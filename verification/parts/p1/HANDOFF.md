## Lower fourth: exact domain and genuine integral

The lower parent at rank three has processing-order coordinates
`t0 > t1 > t2 > t3` and exactly one inherited active cube condition:

```text
t0 + 3*t1 < old.
```

The fourth own-cube condition is not a condition of candidate enumeration.
For each owned cell j, let R_j be that cell intersected with this ordered
parent region, and let lambda_j be its selected cap. Write

```text
g_lambda(t) =
  1_{sum t + 2*t3 < lambda}
    * (2*exp(-gamma)/t3)
    * suzukiContinuousLowerFactor(max 2 ((lambda-sum t)/t3)).
```

The exported `selectedPrefixLowerRestorationIntegral` is the literal sum
of Lebesgue integrals

```text
sum_{j in J} integral_{R_j}
  (g_{lambda_j}(t) - g_old(t)) / (t0*t1*t2*t3) dt.
```

Its definition uses `primeOwnCubeIcoIntegral`; the exported theorem
`selectedPrefixLowerRestorationIntegral_eq_integrals` proves the displayed
single-domain form by reusing `primeOwnCubeIcoIntegral_sub_eq_integral`.
The `max 2` is the proved
continuous extension; on each admitted own-cube side it agrees with the
unextended lower-residual profile. The integral is not defined as a limit
or as a certificate endpoint.

`actualSelectedPrefixLowerOwnCubeSum_eq_cells` is an exact finite identity
for every `N > 1` when the enumeration cap covers `N^b`. It starts with
the literal selected correction on the full ordinary lower carrier,
retains candidates rejected by the old own-cube test, and proves that
outside-cell contributions cancel. The finite correction is multiplied
by `Real.log N / singularSeries N` before it equals the sum of
`actualPrimeBoxOwnCubeMinusSum` differences: these residual sums already
contain that normalization. Both the prime-sum Tendsto and the selected
tree-restoration Tendsto use the same factor. Their limit follows from
the existing actual-prime Ico-cell integral supplier and a finite sum.

The exported hypotheses are separated by what they justify:

| Result | Additional hypotheses |
| --- | --- |
| Exact finite cell identity | `a < b`, `1 < N`, cap covers `N^b` |
| Actual prime-sum integral limit | Fixed `0 < a < b`, eventual cap coverage; no cap legality or old positivity assumption |
| Selected lower-tree restoration limit | `b ≤ old` and every adopted `selectedBoxCapCheck = true` |
| Normalized selected lower density | `2*b ≤ old` and the same finite checks |

`tendsto_actualSelectedPrefixLowerDensity_ceil_normalized` uses the
canonical enumeration cap `Nat.ceil (N^b)` and discharges cap coverage
unconditionally. Its remaining premises are exactly the fixed geometric
range and the finite whole-box checks.

In the normalized result the limit is

```text
(2*exp(-gamma)/b) * suzukiContinuousLowerFactor(old/b)
  + selectedPrefixLowerRestorationIntegral I old nu a b m J.
```

Here b is the fixed positive logarithmic cube endpoint. It is not the
manuscript's imbalance parameter. No assertion that a signed cell
difference is nonnegative is used. This lower selector uses one fixed
I and nu. If an adopted table requires varying cell masks or ceilings
that cannot be represented by this family, its generalized selector and
disjoint composition still need a proved dictionary before this theorem
can certify the complete adopted restoration.

## Finite historical construction

`HistoricalPrefixCapData` consists of rational `a`, `b`, `old`, one grid
size `m`, and adopted finite cell sets with rational cap tables at ranks
3, 4 and 5. There is no target or tested-integer field.

The new values on adopted cells and the effective inherited values are
distinct definitions:

```text
cell3(j3) = if adopted3(j3) then cap3(j3) else old
old4(j4) = cell3(j4 projected to rank 3)
cell4(j4) = if adopted4(j4) then cap4(j4) else old4(j4)
old5(j5) = cell4(j5 projected to rank 4)
cell5(j5) = if adopted5(j5) then cap5(j5) else old5(j5).
```

Common Ico ownership proves these same formulas at actual logarithmic
coordinates. Generic `exponent4_apply_sub` and `exponent5_apply_sub`
provide exact per-cell differences for **any** `f : ℚ → ℝ`; they require
no continuity, cap ordering, or old/new admission premise. The function
f may therefore retain both own-cube indicators.

`levelCheck` checks only the finite rational comparisons

```text
old ≤ cap3(j3), old4(j4) ≤ cap4(j4), old5(j5) ≤ cap5(j5)
```

on the adopted cells. It supplies all h34/h45 premises of the existing
actual historical telescope. `levelCheck_of_selectedBoxCapChecks` also
provides an adapter from the existing whole-box check, with per-cell I
and nu and an explicit stored-cap equality. Each fourth/fifth check uses
its actual inherited old value. A checked midpoint does not license a
different stored cap.

The concrete `upperThirdPolicy`, `upperFourthPolicy` and `upperFifthPolicy`
all use the ordinary upper base at `N^D.old`. The theorem
`upperThirdToFifthSaving_eq` connects the two actual retained polynomials
to `actualHistoricalFourthSaving + actualHistoricalFifthSaving` without
leaving caller-supplied h34/h45 hypotheses. Inactive even parity is
retained; `upperFifthPolicy_eq_oddFirstExitPolicy` gives the exact raw
policy interface for `retainOdd := fun pre => D.upperFifthPolicy N false pre`.

This is a finite level/interface result. `levelCheck` does not prove
whole-box square/envelope licenses, physical support exponents, a boxed
compiler, factorization licenses, distribution, or the final numerical
bounds. In particular a raw `retainOdd` attachment must not be confused
with the manuscript's boxed coefficient without the compiler dictionary.

## Boundary control, fixed truncation and fallback

The finite identities use the original half-open cells and strict prime
cutoffs. They do not delete arithmetic boundary points or replace a
closed arithmetic wall with a null set.

For the lower integral, `ActualPrimeOwnCubeIcoIntegral` uses
`ActualPrimeIcoCellTestFunctions` to majorize/minorize the actual prime
tests by pointwise ramps. Actual residual errors are controlled before
the continuous null-wall identities are applied. The four lower parent
rows are proved nonzero, and each own-cube row has its separate nonzero
proof. The existing `exists_actualPrimeAffineWallStrip_mass_lt` is the
available explicit arithmetic reserve: given eta > 0, first choose a
fixed delta > 0, then N0, then bound the actual closed-strip prime mass
for every N ≥ N0. Its carrier still excludes primes dividing N.

For this fixed finite selector, changes outside its adopted cells cancel
exactly. Thus expressing the full correction on its positive cube does
not discard a small-prime tail or incur an unbudgeted boundary error.
This does not yet prove the error budget for approximating the entire
adopted historical policy by such selectors, nor the manuscript's moving
rough cutoff, sixth/eighth layers, or compiler approximation.
