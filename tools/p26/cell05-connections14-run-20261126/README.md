source/audit pairs, and the exact release submitted to P2. The package is
`cell05-connections14-source-v1.tar.xz`, 145,492 bytes, SHA256
`3334435ea38770c5361d56c52b2595696d2072d55e1e22b0132d81acd03f6188`.
Its 68 regular members are reproduced in `releases/v1/`.

`SOURCE_RELEASE.json` and `LOCAL_VALIDATION.json` describe source preparation.
Their zero acceptance counts are historical and must not be rewritten as cloud
proof results. The eleven focused local tests validate workflow behavior using
synthetic fixtures. Actual submission and execution observations belong in
`../cell05-deployment-20261126/`.

The runner verifies and reuses 88 original P2 supplier source/object pairs; the
selected fourteen targets use 83 of them. It never invokes an old supplier's
normal compilation, kernel checker, or owned audit. Each new target requires
all three checks, for 42 new steps in total. The first three accepted steps are
reused when the continuation starts its separate attempt.

Read `INPUT_CONTRACT.md` together with `RELEASE_ERRATA.md`. The frozen contract's
baseline count refers to 156 evidence files, comprising 18 historical proof
steps and the raw05 kernel addendum; it does not refer to 156 proof steps.

does not close the nine connections requiring the additional fifteen P1 row
