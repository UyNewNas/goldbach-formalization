# Cell05 original parser, typed decoder and finite shape connections

This directory authors new source-only connection candidates for the exact
201042-byte original cell05 input. Its SHA-256 is
`e601ac9ceda569646f06a64f4baddcf9cd405cde1e377a323a238ad4e4681b82`.
All 14 fields, the original order, separators and final CRLF are retained.
The resulting typed geometry must have 28 vertices and 56 simplex rows.

The first batch connects the existing first-five-field metadata owner and
seven complete array values to the original top-level parser. It then
composes the original `decodeGeometry` with the five typed array networks.
The final theorem is about `geometryPacked05` itself. The abstract decoder
composition lemma is only an intermediate step; the endpoint supplies the
concrete JSON and concrete typed lists proved by the original-input leaves.

The second batch transports already authored local shape facts to the same
decoded geometry. Shape means cardinalities, dimensions, index bounds,
uniqueness and record identifiers. Geometric interpretation, simplex
validity, volume identities, integration and completion of P2.6 are outside
this package.

The old six accepted cell05 owners, the remaining 15 row owners and all 73
field owners remain byte-for-byte frozen. The parent reported actual success
of the 15-owner row run `job_03820698aca949449a3c8543e9bb8652`; this source
package does not possess its exact new object/receipt join yet. Field owners
are execution-ready after independent workflow review, with mathematical
acceptance still pending. No missing object pin is fabricated and no old
owner may be recompiled to fill it. A future execution package must join
their exact accepted source/object/receipt contexts first.

Each source batch has a complete environment ownership/type/axiom audit per
owner, exact source and dependency pins, a topological target list and an
archive read back against every member hash. These are authoring checks,
not Lean acceptance. The parent alone schedules normal compilation,
independent kernel checking and full-owned auditing. This directory runs
none of those commands, changes no Git state and leaves new proof evidence
archives on the cloud host.

Candidate archives and small handoff metadata are also copied to
`/workspace/scratch/59264dd64286/p26-transfer` before handoff.
