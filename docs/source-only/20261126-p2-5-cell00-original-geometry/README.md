`20261126-p2-5-cell00-finite-geometry`. It adds two thin consumers, with four
public theorems each. Production files, accepted objects, existing candidates,
dormant runners and cloud tasks are unchanged. It contains no new parser,
decoder, data record, geometric algorithm or finite computation.

import and theorem inventories, full original let-expression correspondence,
source hashes, and forbidden-proof-token/whitespace checks. No Lean AST,
elaborator, compiler, kernel replay, cloud job, production installation or
Git publication was run. The parent owns those remaining steps.

The parent explicitly authorized source-only proof development while
deferring actual compilation. Therefore no test-driven-development or
completion-verification claim is made from these static checks. The future
Lean gates are the semantic tests of these proof terms; source-text checks
do not replace them.
