# Uniformity across the fixed period modes

For each scale V>0, the numerator Wₖ(t) of the positive regular transform of the literal test spectralTest(mode k,V) satisfies

    (1+|t|)³ |Wₖ(t)| ≤ C (1+|k|)ʳ.

The choices of C and r precede k and t. The proof fixes V before choosing them. This is a mode-summation estimate at fixed scale. It does not give a uniform remainder in moving V.

The front function χ(x/V)/x is smooth across zero because χ vanishes on a neighborhood of zero. Each other mode is exactly this fixed Schwartz function times the original exponential phase at x/V. Leibniz's rule bounds each weighted derivative by a polynomial in |k|. Reflection forms the even extension. A continuous linear operator on Schwartz space preserves the property because each output seminorm is bounded by finitely many input seminorms. This applies to both ordinary Fourier transforms and their fixed frequency changes.

The intervening substitution u ↦ cosh u needs a separate estimate. The original derivative recurrence expresses the bth derivative as A(cosh u)+sinh(u) B(cosh u), with A,B formed by differentiation, linear combinations and multiplication by the coordinate. Each of those operations preserves polynomial input prices. The inequalities |u|,|sinh u| ≤ cosh u give the two needed seminorms. The existing regular transform identity then identifies the computed Fourier function with the actual numerator, including the removable value at t=0. This price can pay the principal-spectrum mode sum against the cubic estimates at a fixed native level and fixed marks. The mean-level induction requires separate bounds. Source-level only.
