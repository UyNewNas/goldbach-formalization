# Paying the two ordinary spectral terms

The initial trace uses the single test \(\Phi(Yx)\). The trace after the level switch uses the two-cutoff test \(\Phi(Yx)\Phi(4\pi\sqrt{mn}/(dQx))\) with both endpoints \(m,n\) in the same original interval. The quantities \(R,C\) in the code are the actual principal and incoming quadratic forms of those tests at infinity.

For \(M=2^j-\tfrac12\), write \(L(Y)=1+\log^2(2Y)\). The estimate \(\sum_{B<d\le2B}(|R|+|C|)\le A_\varepsilon L(Y)(B+M^{1+\varepsilon})M\) applies to either test at any positive \(B\). In the initial mean its contribution is additive. In the switched mean the proof sums this bound over the six returned dyads and four input shoulder dyads that support the two complete traces. The main returned prefix maximum has the same coefficient as before this payment. Its exponent and its level windows are unchanged.

For each fixed \(0\le T<1\) and \(\varepsilon>0\), the constants \(c,K,D,Y_0\) precede \(Y,Q,\omega,j,a,b\). The inequalities concern the native exceptional energy with \(\tau\le T\). They retain separately the exact norm sums of the complementary \(\tau>T\) slots on the initial and returned sides. The later positive-frequency vanishing argument is a separate use of this formula at \(T=3/4\). The six-window expression is the literal support statement of this cutoff. Its four parent windows, when needed for \(Q<q\le16Q\), have their own parameters \(2^bQ\).
