# Level ranges of the reflected cutoff

Write M = 2ʲ − 1/2, C = πMY/Q and retain the actual integer marks m,n ∈ (M,2M]. A nonzero reflected test at level d forces 4πY√(mn)/(dQ) ∈ [1/4,25/4], by the support of both bumps and the exact same-infinity reflection. Consequently 16C/25 ≤ d ≤ 32C. Since 16/25 > 1/2, six fixed windows with lower endpoints C/2, C, 2C, 4C, 8C and 16C cover every such d, including the closed upper endpoint. Each window uses the actual T08 `classicalLevels` predicate (B,2B]. Real endpoints and the block j=0 are included.

At entry, the four bumped level weights g(q/(2ᵇQ)), b = 0,1,2,3, dominate the indicator of the full printed range Q < q ≤ 16Q using the respective plateau [1,2]. Thus both sides have concrete covers with cardinalities independent of Q,Y and of the two Fourier marks. Further use in induction must keep the largest scale constant from these windows.
