# P2.10 complete Winner9 seed: finite-data import boundary

SOURCE ONLY. No Lean compilation, kernel replay, object-cache qualification,
or proof acceptance is claimed by this package.

## Scope

The selected P2.10.4 target is the complete original Winner9 terminal and the
seven existing SeedRefinements APIs, including original_seed_refined_floor and
refined_record_sum. It does not include the other 86 cell integral bounds,
SavedGain, all22, or hUpper.

The old seed candidate imported P2OriginalSaving18UnequalIntegral only to
supply a transitive dependency to Saved86. Its historical project-import
closure has 881 modules. Importing the unmodified CellIndexedArchiveWeight
alone still reaches 218 historical project modules through SourceDictionary.
Those are source-graph counts, not new compilation or acceptance counts.

This package retains the original Cell type, original globalIndex mapping,
all 87 numeric records, the original archived accessor, the existing complete
Winner9 terminal, all seven public seed statements, and all seven bodies from
the previously selected seed candidate.

   only its SourceDictionary import changes to ArchiveIndexDefinitions.

   its unequal-integral import is replaced by explicit ArchivedValueDefinitions
   and CellIndexedArchiveWeight imports.

The only external project imports of this six-module set are the already
existing P4AOriginalFull87SourceDefinitions and P2Winner9CompleteSeedTerminal.
All other external imports are Mathlib. The eleven existing definition cores
are untouched. In particular, originalId is not added to the accepted
AscendingFourteenSourceDefinitions file.

## One owner per original declaration

original-owner-followup.patch is for original module INSTALL paths, not for
editing frozen source archives. For AscendingFourteenAffineSource and
Full87SourceDictionary its preimages are the exact postimages of their
existing 20261124 definition-core refactors. ArchivedIntegralRows uses its
unchanged original source as preimage. SOURCE_RECEIPT.json binds all three
preimages and postimages by SHA-256.

Do not load an unrefactored former owner beside these small cores. The paired
patch removes only the four moved declarations and imports their new owner.
It preserves every other old declaration and mathematical body. It is not
applied to active repository sources by this package.

The two former semantic-owner variant conflicts recorded for the broad
unequal/all22 graph are not reached by this six-module seed graph. This does
not resolve or certify those later graphs.

## Saved86 direct dependency

saved86-explicit-import.patch adds the existing P2OriginalSaving18UnequalIntegral
import to Saved86, which directly uses Paid57, originatingCell, and
original57_archived_cell_le_integral from that module. It changes no
Saved86 declaration. This prevents the seed supplier from remaining the
accidental owner of that transitive import. Saved86 and its unequal supplier
remain outside the selected P2.10.4 compile target.

## Source verification and remaining gates

Every retrieved original UTF-8 source was checked against its recorded Git
blob identity, byte count, and SHA-256. The four moved declarations are
identical after the existing receipt's LF/trailing-blank normalization.
The two unchanged provider files are byte-identical. ArchiveSourceIndex and
the seed candidate differ only in their specified import lines. Both paired
patches passed git apply --check and exact-postimage comparison on disposable
copies. No active source or accepted core was patched.

Normal strict compilation, complete owned-declaration/type/axiom audit, and

11,026 original numerical rows; this package contributes no numerical-row
