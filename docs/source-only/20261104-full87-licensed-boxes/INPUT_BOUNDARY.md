# 稿内证明与稿外输入边界

本包只新增 P1.4 稿内有限构造及其精确语义衔接。稿外解析输入记录、不新增实现；也不以新公理、占位证明或许可字段替代稿内缺口。

## 本轮稿内对象

- 原许可过滤器的完整比较程序：原动态 guard + 动作自身的量化后下侧平方许可 + selected-tent 上侧扣减。
- 已过滤最大值的实际获胜动作及其 mask，不要求它达到已被过滤掉的旧 raw 最大值。
- 不二次舍入的有理常数查表、同一祖先盒的值/标签认证、等号及拒绝盒精确回退。
- 原87域上的同一新 cap、同一新树成员、联合网格遗漏。权重可积性在通用 L1 结果中仍显式要求，未实例化的实际奇异核没有被当作已处理。

## 稿外输入：仅登记

PNT/Mertens、原稿引用的经典分布或谱论结果仍为外部输入登记项。未重新核实的定理版本、编号、精确范围、归一化、阈值及正式来源保持待核实，不计为已经供应。本轮没有为它们新增 Lean 证明、公理或条件 wrapper。

mathlib 实数、有限集合、测度等基础结果按既有固定版本复用；未升级或重写。已有依赖中的外部未验部分仍需未来传递审计，不因本包的静态检查而获得验收信用。

## 不能转为稿外的黄色义务

saved 全档几何/源域/原积分与数值端点绑定；raw/finite/filtered 的 signed gain 和舍入损失；本稿实际核可积性、素数均值适配、全部 changed/tagged 算术覆盖；独立编译与密度 reserve 付款以及同 rho 总装。这些均为稿内义务，即使需要引用外部定理也不能将整个目标改作输入。
