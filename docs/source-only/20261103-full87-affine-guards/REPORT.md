## 4. The floor itself is a finite threshold table

For d=n+1 and y=clamp(x), the old protected rounding uses

```
Q_n(x) = max(0, (floor(d*y)-1)/d).
```

The new exact identity is

```
Q_n(x) = max({0} union { j/d : j in integers [0,n], (j+1)/d <= y }).
```

It holds for every real x, including the clamped nonphysical inputs. Equality at `(j+1)/d` is admitted: this is essential to match the original floor convention. `rounded_eq_threshold_max` derives the identity from integer floor inequalities; no sampled numeric comparison is substituted for the proof.
