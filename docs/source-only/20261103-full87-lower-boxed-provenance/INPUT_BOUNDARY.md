# 稿内证明与稿外输入边界

本轮范围：只推进 P1.4 稿内构造与衔接。稿外输入只登记，不新增实现，不以新公理、占位证明或输入字段替代稿内缺口。

## 本轮直接使用的既有输入

| 输入 | 处理 | 状态 |
|---|---|---|
| 原4/5档案、原第三层表、完整6层构造 | 原样复用仓库中已存在的定义与候选供应 | 继承来源；本轮未重新读取 NPY/BIN；传递闭包未编译 |
| 有限最大值、protected quantizer、仿射比较与标签认证 | 复用既有模块，新增本稿需要的原行来源转换 | 新转换仍为未编译候选 |
| mathlib 有限集合、实数、测度与支配收敛 | 固定既有版本，通过原依赖导入 | 不重写库定理；不是本轮新实现的稿外证明 |

工具链保持：Lean `leanprover/lean4:v4.33.0-rc1`；mathlib `e4c91783ca8e6a7c693ae624ade32fd22d4e43c1`；原上游 `subfish-zhou/goldbach-lean@09b97db5764ade1246bfb77206baa1b124760958`。

## 项目稿外数论输入：登记，不实现

PNT/Mertens、原稿确实引用的经典分布或谱论定理，只保留为稿外输入审计项。本轮没有新增它们的 Lean 实现，也没有新增假设它们成立的公理或 wrapper。

本轮未重新读取完整稿件及这些外部原文，因此不声称已固定它们的精确定理号、参数范围、共同阈值或归一化。后续输入登记需逐项记录：出处与版本、精确陈述、适用范围、归一化、调用位置、形式化来源及核验状态。尚未核实的项目应保持“待核实”，不能被视作已供应的前提。该清单是范围登记，不是完整引用清单或已验输入清单。

## 不得转移到稿外的剩余义务

以下均属于稿内未闭合工作，继续保持黄色：

- saved 全档几何认证、实际源域及原数值积分/增益覆盖，不能由原87交叠域准入等价替代。
- 第六层不安全余量补集上的最终合法动作/继承策略及损失，不能通过删点或置零消失。
- 本稿 raw/finite/boxed 同一实现之间的 signed gain、舍入误差和数值 saving 搬运。
- 本稿实际核可积性、素数均值适配、changed/tagged 覆盖和两本 reserve 的具体付款。它们可能使用稿外定理，但实例化与本稿误差账目仍是稿内证明。
- 本稿 P3 强移动分布和同一 rho 的具体总装，不因涉及谱论就自动归为稿外输入。

同源编译、kernel replay、传递公理审计和独立复核是验收事项，不是可以免除的稿外数学输入。
