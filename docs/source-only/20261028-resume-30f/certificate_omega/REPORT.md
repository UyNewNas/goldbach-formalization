## 本批实际推进

`OriginalPairedN48RawQueryFamily` 沿原全局 cell 数组定义每次 raw query 的 `floor(lo*8192)`、`max(first,ceil(hi*8192)-1)`、drop/take 和零起点 fold-max。对任意 `2 <= lo <= hi < 10` 写出真实 cell coverage 与原 query numerator 的 uniform Buchstab 上界推导，包含单点区间及右端恰落网格的情况。它复用 C 的真实 per-cell `h^3/6` 误差与 `h^2/4` bulge，而非假设待证 uniform bound；原预分配字段对 canonical arrays 的身份被推广到每次 raw query。

`OriginalPairedN48AllNativeQueryGeometry` 直接从原整数左右端点证明所有 `SourceRow`（term0/term1、所有 indices/ties）均满足 `2 <= rawLower <= rawUpper <= 8`，并在原 `nativeBox`、`fullParent` 上保留真实 omegaArgument 的包含关系。`rowOriginalNumerator` 与 `rowCanonicalNumerator` 的同一 query 身份是符号算法身份；没有生成整数值。对原预分配全局数组的实际 query 上界仍依赖 D 尚未执行的 canonical producer 有限证明提案。

`OriginalPairedN48Q112ClampedReceiver` 保留原 `max(0, baselineLo-costHi)`、Q112 端点和 Q80 保存 floor。正差分支把整数交叉乘不等式还原为同一父域真 switched integral 的成本上界；负差分支由原比较强制 `floorQ=0`，再用独立解析的真实 Buchstab 全局 C0 cap。这避免把零 floor 错当成必须满足未截断差值。该 receiver 的一般 interval/query 输入在下一模块由实际对象消去。

`OriginalPairedN48RequiredRowQ112Bridge` 消费独立冻结的 F `P2N48OriginalHighBlockWeights`：原 J112 `sourceSmallLog`、signed moments、factorials、零起点 fold 和左结合 blocks 已连接所有高带有序 keys 的四种 tie 真实质量，也覆盖冻结的 `actualRetainedRows`。每行 baselineLo、costHi 使用同一 `originalRowZToken` 和该行原 raw query。`actual_required_same_parent_directions` 不要求调用者提供 hZ；`actual_required_row_old_cost_of_check` 只留下该行原有限整数 max-floor 比较，不假设 hOldCost 或最终 gain。

`requiredOriginalNumeratorTable` 按原 `actualRetainedRows.toList` 生成 `(完整SourceRow, 原query表达式)`，保留 ordinal、term、indices、method 与 saved floor，不是任意 per-key 数字。`allRequiredOriginalFloorCheck` 精确取该行族的逐行原比较；闭合 `decide +kernel` 和随后 `actual_required_all_row_old_cost_proposal` 都只是未执行源码提案。没有把整数合计冒充真实积分。

## 精确覆盖边界与仍欠证据

- query 几何覆盖全部 SourceRow，两种 term 和所有 ties；真实质量/同父端点覆盖全部高带有序 keys 及实际 `actualRetainedRows`。这两个覆盖范围不能混同。
- actualRetainedRows 是冻结源所指定的 retained 子族；它不是原稿完整1190700行负域覆盖。其他行/方法、uncovered complement、完整 physical functional、原 paired mask/fibre/reserves/current-c 链仍需相应全覆盖证明。
- D 的 CanonicalLogGuards/CanonicalCellSigns、独立 peer 的96个 scalar bin ratio 分母正性以及本批 all-required floor 决策项均未执行、未获接受。`Finset.toList` 代表元/可归约性、closed decision 的 elaboration 与资源可行性均未验证；不能宣称逐行通过。
- 没有 materialize 任一新 numerator 整数或原 endpoint 数字表；表达式列表不是求值后的 literal 整数表。若要求历史 serialized/transient dump 身份，仍需同一原算法的 byte/serializer 绑定。Lean 预分配算法身份不等于恢复 dump。
- 全部源码尚需用户的 compiler owner 核验。此处未运行 Lean、lake、kernel、数值/数组生成器或 checker，也未查额度或派生代理。

独立依赖方向为 lower_functional 的 geometry/true-mass/original-token 源码 → 本批 query/端点/floor receiver → 下游 functional。没有引用下游 functional 结论反证其输入，也没有将 hP1/hP2/internal K/PP 或 certificate 成功移作原始前提。
