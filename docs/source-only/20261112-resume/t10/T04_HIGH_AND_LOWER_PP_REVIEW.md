## 同一系数的真实分组

1. 固定 ω=νβ²、ℓ=νβ、νv=19/96、w=N^ω、z=N^(19/96)、L=N^ℓ、cap=N 及空历史标签。在实际 `rho_at_product` 中按系数选择正或负 small-Rosser 权。非零性给出小因子 a<L 和实际粗占用。最小代表取自同一完整有序标签词的真实 rawSupport。分组选择可依赖这个固定代表、局部 x 和 U，同一盒内的每个求和素数元组共用它。
2. 最大粗素数的坐标严格大于 μ 时，三个互斥情形分别是二阶命中取 p₂，三阶命中取 p₂p₃，双未命中取 p₁。二阶替换进入实际三阶准入，三阶替换改变后继。两者使用全闭格已有的选中及余部平方门。双未命中从被保留的第一步和实际 p₃≥w 得到整第三格的真实 Γ 及其 2e 余量。保留的后继按奇偶逐步延伸到任意长度，包括偶长末尾。低首坐标与恰为 μ 的代表留给低区。
3. 每一正、互素、实际素数的自然细标签整数上端介于 p 与 N^τ·p。余部预算同时计入已移除的选中槽和余部当前平方的第二份指数，费用界为 τ(J₀(ω)+1)≤ζ。原满向量和去选余部两种平方预算均有出处。局部取 θ=M+6ζ、D=x^(M+4ζ)，在 D/(A·b₊)≥1 与 <1 两个分支分别分配余部或重新分配全词。这里 A=U/x^ζ。原区间 x^(2ζ)≤U≤x^(1/3+ζ/2) 整段给出 x^ζ≤A≤x^(1/3−ζ/2)。
4. 对 0<ζ≤min(uniformMargin/64,1/400,e/32)、2ℓ≤ζ/16、κ≤ζ、x>1、x^(1−ζ)≤N≤x^(1+ζ)，设 ε=ζ/100、σ=7/32。Q₁,Q₂ 是前两组的上端，Q₃ 为第三粗组上端乘 x^(2ℓ)，实际 a≤x^(2ℓ)。源码严格给出四式

   - Q₁ < U x^(−ε)；
   - U² Q₂ Q₃² < x^(1−8ε)；
   - x^((1+3κ)σ) U Q₁ Q₂⁵ Q₃² < x^(2−15ε)；
   - U^(23/16) Q₁ Q₂^(73/16) Q₃^(39/16) < x^(2−15ε)。

   第三式的实际 L23 余类为偶目标 N，调用它还须证明 N≤x^(1+3κ)。该比较没有从任意 κ≤ζ 及 N≤x^(1+ζ) 自动推出。原局部尺度 x≳N^(1−κ) 和先定的充分小正 κ 在大 N 下给出该比较。Prop. 5.2 的独立余类范围还要求 N<x^(1+ε)。原稿给出 κ<ε/(2(1+ε)) 的选择。原上限 0<a≤1/800、νv=19/96、真实局部尺度，以及原稿后续对 12ζ<a/2 等要求，仍应在共同选择中逐一实例化。新增细调度可对同一 β 再压低 ℓ 和 τ(J₀+1)。
5. `GroupedAtoms.attached` 在固定受支撑的小因子、降序标签词和任意实测试函数上给出原占用系数之和。所有组均为真实的互素细素数区间与粗素数集之交，每个规范化三组系数的绝对值至多 1。一个原词倒重复标签阶乘乘三个组阶乘。全乘积 Möbius 仍在等式内，跨组素数相等时它使该项为零。真正的 L23 应用还须汇合全部小因子和盒、对接第三组附 β 的有界卷积、处理解除平方自由限制的费用，以及真实外层 SW、粗糙性、对数精度等前提。原命题要求三个有界、与余类互素的模数序列和两个外层序列。[L23 v1，定义 2.1 与命题 5.2](https://arxiv.org/abs/2309.08522v1)

## 低区与 signed trim

`LowActualRoot.owner` 对任意满足实际 rough-support 前提的秩至少三代表，在真实 p₃≥w 处给出原半开第三格、该格实际 cap 和首坐标 ≤μ 的等价判别。`LastOddSupport.full` 在最后一次被测试的奇长前缀上读取真实 affine program 的标量，对全词给出同一普通 Rosser 预算。偶长时，末素数的严格排序和前一奇阶的真实准入给出延伸。`SelectedPrefixSquares.complete` 输入具体掩码、该掩码每个余槽的原平方门和完整词平方预算，按原指标次序推出除以所选积的全余词预算。其输入的逐余槽门仍需从实际赢家提供；它未构造全低区赢家。

T05 的 `eventually_signed_trim` 在同一个 Q、ρ 上支付的是**外层**素数词总积截断 Wₛ→Vₛ 的差。T04 三个引理处理的是**模数内部**粗素数词的策略、掩码和平方预算。T05 的 `eventually_trimmed_exact_atlas` 还留有 Vₛ 上的有符号总误差。二者可并用，不能互相消去前提。低区还需逐个识别原种子、第四、第五、第六和第八赢家的实际标量、整盒掩码与许可，必要时使用原 W 修复。已核查的稿件将这些步骤与谱估计明确分开。真实全族调用、平方移除和最终有符号分布估计属于尚待建立的形式数学，现有证据没有给出原稿矛盾。
