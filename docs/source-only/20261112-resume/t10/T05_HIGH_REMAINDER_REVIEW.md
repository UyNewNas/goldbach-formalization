# P4B 的实际高秩余项

本包给实际 RealB 正计数留下一个明确的高秩带符号积分，并把其中有中段、首个粗素数坐标大于 μ 的部分接到原稿的四条长度不等式。该积分的绝对估计仍欠。P4B.4、hUniformPP 和 hUpper 保留原状态。

## 同一物理系数

原 GlobalPayment 的三个公开定理 eventually_each_block、eventually_original_prime_rank_two、eventually_original_atlases_rank_two 的签名字节均保留。新选本把原证明共用的模数条件写成正模数、与 N 互素、绝对系数至多 1、d<N^(2/5)。进展对任意满足条件的有限子集成立。低乘积区将有限集外的权重延为零，高乘积区将同一权带入原分块绝对误差和倒数质量。原低秩定理重新取原 carrier；此前成功的编译不能为改过源码的依赖背书。

在原 Q 上，actual_class 由原支撑逐点给出这些条件。完整误差可按任意此类子集拆成两项，支付所删子集后仍取该 Q 上原矩形系数 c。先用全模数高度划分，再用 lowRank⊆below 分别支付得到的 wholeHigh 曲线，两个联合 atlas 的差也有同一误差尺度。完整乘积 d<N^(2/5) 的不独立硬截没有留进后续三个模数因子。均匀阈值在集合、权重与合法 s 之前；子集上的计数项与精确互素均值使用同一 c。由局部径向截断和 proper-power 桥得到的完整余式仍明示要求实际 c 的严格 599/1000 支撑。

## 原母函数、预定宽度与实际 RealB

我核对了原来两个 atlas 的分拆、rawAtlas_eq_normalized、normalizedAtlas_pair_eq_rowBank 及 rowBank_eq_modeBank。这里先合并 medium/no-medium 的带符号原和，再对两个原组的 HB 整数取行。每个原组都有自己的对数分母，整乘积截断 η、两组 ψ、各阶 HB 的符号和角色以及单位坐标均来自同一整型 profile。各个 Fourier mode 的目标为 N，模数仍在同一子集，原 rho 同时乘在同余与除以 φ 的互素核上。此等式允许两分支彼此抵消，不能给它们分开取绝对值。

两组各至多六个坐标。积分的是原 amplitude 的范数，含 frequencyScale 的维数幂归一化。逐母的实际 mixedD 界是 C/s²⁴，再按原 chart 与全部 HB 块和原标量绝对值累加，得到 C·logScale¹⁴/s²⁴。预先取 m(N)=⌊log N⌋、s(N)=1/(m(N)+1)，得到 C(log N)³⁸。真实互补乘积按右闭 dyadic owner 额外分组一次，级数至多多一个 log，故总成本 C(log N)³⁹。这些是全振幅费用，在任意快增长的分辨率下没有同一个 38 次幂断言。

原 exists_same_coefficient_trimmed_count 的选参次序是先得 s₀ 和 N₀，再对所有 0<s≤s₀ 及所有充分大偶 N。故能在同一 N 上代入 s(N)。给定原 beta、nu、对应 k 并满足明示的支撑与尺度条件，最终右端是实际非负主质量乘 physicalDensitySum(Q,c)，加同一 c 的 wholeHigh 积分实部及 η·singularNormalization N。采用的是完整频率积分。旧 attachedUpperCoefficient 消费者的截频验收不可直接迁给当前 c。[原 RealB 定理](https://github.com/UyNewNas/goldbach-formalization/blob/51859a24c91580f885afd2a781dcb48b07177529/docs/source-only/20261112-resume/t05/P4BOriginalFiniteTrimmedCount.lean#L75)

## 中段、互补纤维与原 M

先由原 HB 块向量确定 firstMedium，再按其余全部整数的积选一个右闭 dyadic 标签。标签独立于所选整数和 rho。局部 x 是两个真实块下端之积。活纤维中一个 integerProfile 非零的点，同时给原两个母窗和整积截断的支撑，固定标签后 (x,U) 对同一纤维恒定。whole-medium 的 U、beforeHBCutoff、原目标 N 使用同一参数；有 x≤exp(1)N、N≤x^(1+κ)、x^(2ζ)≤U≤x^(1/3+ζ/2) 及原粗度上下界。

零纤维的 Fourier integrand 可以非零。新增 fibre_integral 先用幅度乘单位模相位的可积性与有限求和交换，把完整积分还原到同一 fibre 内逐字的 integerProfile。dead_fibre_integral 再在物理端逐项取零。eventually_fixed_live_window 只需该纤维有一个非零点，对整块使用同一组尺度，允许该纤维里出现 profile 为零的其他整数。

对 wholeHigh 上实际非零 c，active_word 从真正 small-Rosser 两号与粗系数乘积，找回同标签的最小 rawSupport 代表以及至少三个原粗素数。其首坐标严格大于 μ 时用 71b 已审的三组真实端点，并把小因子附到 Q₃。四式逐条保留原 U、N^(7/32) 及 Q₁,Q₂,Q₃，含原稿所需 κ≤ζ/10000、σ=ζ/100。这里给出的是进入原 M 的几何条件。个别粗 HB 角色的辅助 Siegel–Walfisz、其余可除条件、带完整 β 的卷积恢复、全局平方碰撞(含整积=N)、no-medium 两长/一长槽及低首≤μ 部分仍有独立实际估计。原稿列明这些前提和预期绝对误差。[原 PP 插入 §1–5](https://github.com/UyNewNas/chen-imbalanced-semiprimes/blob/9731290e8f53cffda44129906cde6a965eaa869b/proof-library/source/distribution-prime-product-completion-20261010.txt) · [原中段 §1、§10](https://github.com/UyNewNas/chen-imbalanced-semiprimes/blob/9731290e8f53cffda44129906cde6a965eaa869b/proof-library/source/distribution-medium-completion-20261010.txt)
