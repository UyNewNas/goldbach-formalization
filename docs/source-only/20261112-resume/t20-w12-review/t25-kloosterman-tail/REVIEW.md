# T20 独立复核 · 正号 Petersson 权二的 Kloosterman 几何尾

**限定通过。** `original_weight_two_absolute` 给出实际 Γ₀(z) 在 ∞ 与尖点 1 之间、正频率 m,h 的权二 Bessel 模数级数绝对收敛。`physical_twisted_summable` 另给 Hecke 极限所需的算术余量。固定第一频率 m≠0 后，同一个非负上界适用于所有第二频率 n∈ℤ，包括零，并允许 n 和第一频率的单位因子各自随模数改变。

## 固定频率如何取得节省

在素数模 p 上，将全部双频率的四次矩完全展开。两个独立的加法特征正交关系各给一个 p，因此总数是 p² 乘以满足 (x+y,x⁻¹+y⁻¹)=(v+w,v⁻¹+w⁻¹) 的有序单位四元组数。当 x+y=0 时，y=−x、w=−v，有 (p−1)² 个解。其余情形由和非零与倒数和相同得 xy=vw，故后两项是前两项的一种排列。这两部分给总数上界 3(p−1)²，p=2 同样成立。

若第一频率 a 在模 p 下非零，(at,b/t) 随 t 遍历 p−1 个不同频率，而相应 Kloosterman 和全都相同。保留这批四次矩的非负项得到 |Kₚ(a,b)|⁴≤3p²(p−1)，允许 b=0。由此在仅出现一次且 p∤m 的素因子上使用 2p³ᐟ⁴。p∣m 的素数和所有指数 k≥2 的素数幂只用 |K|≤φ(pᵏ)≤pᵏ。

对互素分解 d=qr，原 CRT 将第一、第二频率同时乘以 r 在模 q 下的逆元，另一侧同时乘以 q 在模 r 下的逆元。原单位换元恒等式将地方第一频率还原成固定的 m，地方第二频率允许任意改变。从而得到乘性上界 Bₘ，Bₘ(1)=1、Bₘ(p)=2p³ᐟ⁴ 或 p、Bₘ(pᵏ)=pᵏ（k≥2）。任一 d 上再乘局部单位也保持这个上界。整个证明只要求 m 为固定非零整数，无需假设 m、n、d 两两互素。

## 全部模数的统一尾

在权 d^(−2+δ) 下，取 0≤δ<1/4。p∤m 的一次项为 2p^(−5/4+δ)，p∣m 的一次项为 p^(−1+δ)，后者只涉及有限多个素数。每个素数的二次及以上项之和为 p^(−2+2δ)/(1−p^(−1+δ))。分母统一大于等于 1−2^(−1+δ)，两个无穷素数和都可用收敛的整数幂级数控制。

对每个有限素数集先累加各素数幂，再展开非负的有限 Euler 乘积。有限积被其地方非零项总和的指数函数控制，遂得到全局 Mₘ,δ=Σ Bₘ(d)d^(−2+δ)<∞。核对了 mathlib 的 `summable_and_hasSum_smoothNumbers_prod_primesBelow_tsum`，它在这里仅要求各地方级数收敛。每个有限模数部分和都在某一这样的乘积内。该证法对 δ<0 也成立。任取 0<δ<1/4、D≥1，算术尾 Σ_{d>D} Bₘ(d)/d² ≤ D^(−δ)Mₘ,δ，常数独立于第二频率、其逐 d 的选择及 z。这也控制了 0≤s≤1 时额外出现的 d^(−2s)。

## 原尖点、物理 Bessel 核与边界

在原 `cuspOneMatrixSum_eq_phase_mul_kloosterman` 及 `bareCuspTerm` 所用的几何中，z,d>0、(d,z)=1、C=d√z。矩阵相位和严格等于 e(h/z)K_d(m·inv_d(z),h)。相位范数为一，而且 inv_d(z) 在当前模数 d 上确为单位。相同的 Bₘ 可逐 d 应用，d=1 也包括在内。z=1 且 m=h 的零分母对角轨道单独进入 Petersson 公式；本次尾从正模数开始。同尖点 ∞ 的 z∣d 子级数也继承同一算术尾。

对实际 m,h>0，令 A=4π√(mh)。源码把原 `generalJ_eq_symmetric_poisson_integral` 代在阶 ν=1。积分核的模为 √(1−t²)，在 [−1,1] 上至多为 1。由此得到对所有 q>0 的 |generalJ(1,q)|≤C₁q，C₁ 是源码中固定的 Gamma 常数。逐项得到

    |S∞,1(m,h;C) J₁(A/C)/C| ≤ C₁ A Bₘ(d)/(z d²).

因此实际几何尾至多 C₁ A Mₘ,δ D^(−δ)/z，对正的第二频率 h 至多按 √h 增长。固定权二 Petersson 常数 2πi⁻² 只把范数界乘 2π。具体源码终端给绝对可和；带 D 的速率来自上述同一主函数和冻版数学证明中的逐项不等式。

这一结果可以交给 T21/T22 的权二几何侧使用。Hecke 正则化后其余核与傅里叶系数的极限、谱侧再生向量和两侧的 Petersson 识别仍需各自的证明。本文的许可不含全谱恒等式、一般尖点的几何分解或逐复合模数的 3/4 型上界。
