## 原四带母式如何下放到原收据

ReceiptFourBand 在原 sieveCarrier 的每个 ℓ 上使用 native secondFunctionalMother_label_weight。此时色带由 (N−ℓ)/d 的不同素因子构成。可在求和前同时筛选母数、锚点、负窗和正标签。再交换 ℓ、q 两个有限和，用 q≥a 的严格截断协议接到 d q 的同 E frozenCount。不能由只对总和成立的不等式推得这一步。三个负窗分别是 [a,f)、[a,c)、[a,e)。

## 冻结物理层上的完整平方

对两类增强根，a≤x<e=57/224。升支 (1+x)/2 和降支 57/64−3x/2 都至少为 57/112。原 [0,1] 半开网格在 n=111 含点 57/112。上端点 1 的独立所有权也满足下界。累计 frozenLevel 保留所有旧格，故任一预先选定 n≥111 和任一 N 的真实增强根满足 2x<57/112≤λ_f。enhanced_root_gates 由原根槽 [⟨x,true⟩] 直接给出根的两套平方；enhanced_history_physical_gates 和 enhanced_bank_children_gates 传播至实际位置及被选子窗。经典 U3 的 x≥e 分支仍用原 ν<1/2 的 BV 接口。

对实际列表中的每个平方，写 T 为已走过的指数和。在 selected-remaining 路上，起始 T 是整个 selectedWord 的指数和。真实整数词给出 N^T=B 与 N^x=q，其中 q 为不整除 N 的素数。若 T+2x=λ_f，则 Bq²=Q，与旧源 root_power_ne_coprime_multiple 矛盾。enhanced_history_strict_physical 在候选列表上逐槽使用这一事实，给出**同一个物理 λ_f 上**的严格版。有限 N 的点态严格与所有 N 共用一个正间距是不同的量词。近边界的总 θ 质量及其预算仍由 T23 相应工作处理。

## 本包边界

固定查询和动作方向均未把收据补集默认为零。筛过的负子项可能有比普通族更小的计数；把普通下界直接乘原前缀的 Θ 会漏掉补集。原稿的正盒估计以及 L23 对带符号素数槽的分布结论，仍要在实际族的系数、筛限和基线下对接，或走只在最初正根上扩大、全程保留普通接收者的归纳。这里完成有限计数和物理平方部分。持续待证的还包括相应解析额度、共同误差控制和最终 U3/U4 H430 上界。
