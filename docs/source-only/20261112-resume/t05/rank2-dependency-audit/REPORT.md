## 权函数和同系数

`P4BArbitraryWidthUpperPairProfile.profile` 与 `integerWeight` 直接定义真正两坐标、四道墙的权。其 `original_caller` 在标号素数对上给出原值，`licence` 构造实际的 `Fin 2` 环境函数、光滑性和整数值一致性，`original_signed_source` 保留完整有限 `Q, ρ`。独立的 η 是后续第五个变差因子。`P4BOriginalRankTwoGlobalPayment.eventually_original_prime_rank_two` 对这组函数用 `exists_actual_prime_local_conductor_saving`，对误差的互素均值用绝对权重预算，对小乘积用同一有限系数的有符号行估计。

前三件随 `P5ActualIndependentUpperPairProfile → P5NativeSelectedFourOrderedEuler → P5NativeSelectedFourIntegerProfile` 进入模块依赖图。两坐标所需的导数字典和局部等式来自 `P5ActualIndependentUpperPairProfile` 自己的 `actual_ordered_word_dictionary` 和 `eulerWord_eventuallyEq`。其融入的 `eulerOne_eventually_zero`、`eulerWord_eventually_zero` 是局部函数等式的微分规则。四维任意原稿 W 的 binding、四维全谱分配均没有作为这笔秩二付款的前提。

## 从原素数行回到两个图表

`P5IndependentPrimeSourceWordDictionary` 使用 Mellin 文件中的有限线性泛函及核。核为同余 `b ≡ T (mod q)` 的指示函数减去 `gcd(b,q)=1` 的指示函数除以 φ(q)。`original_prime_discrepancy_words` 的有限双向重排保留这些因子及原有符号系数。随后 `original_prime_allGroup_discrepancy`、`original_prime_discrepancy_mode_carriers` 和 `eventually_subset_atlases` 给出 `eventually_original_atlases_rank_two` 所需的精确两表联合和。这里没有调用带 `hmode` 前提的条件估计。

`P4BActualUpperRoughPrimeReserveZero.actual_original_chart_windows` 在每个非零原图表上从同一真实素数词导出 `js.length=2`、逐坐标原 `psi` 窗、以及 `N^(νr) ≤ p ≤ N`。原 cutoff 模块第 208 行的定理给 `beforeHBCutoff K js < N^(nu*r)`。它先选依赖 `K, νr>0` 的 `N₀`，然后对所有活动词、合法宽度和 `Q, ρ` 同时成立。实际调用第 101 和 113 行取 `k=2`，后接 `roughWord_one_on_prime_word`。任意原稿 W 的标记等式只出现在 cutoff 文件后部单独的三线性定理。
