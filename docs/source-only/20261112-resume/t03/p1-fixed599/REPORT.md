# P1 在固定指数 599/1000 以上的两侧实际系数

**对每个完整模数 `d ≥ N^(599/1000)`，P1 原 raw 和 licensed 两棵策略在该模数上的 `actualSmallRoughRho` 相等。** 两侧使用同一个 `N,cap,w,z,L=N^epsilon`，其中 `0<epsilon≤1/1000`。结论覆盖等号及第一个超过实数截止的整数。对任意测试 `F`，原 raw 外侧账单、87 个单元的三类绝对叶账单和 licensed 外侧账单同时为零，完整物理差也为零。T10 已独立读回源码、原声明及三个安装后像。验证状态为 `SOURCE_ONLY_UNCOMPILED`。[系数与账单终端](P4AOriginalFull87Fixed599PhysicalRho.lean)

## 原策略、实际乘积与整数截止

这里的 raw 是 `P4AOriginalFull87CompleteSixthDispatch.policy e q om N`，licensed 是 `P4AOriginalFull87LicensedSixthPolicy.policy (width r) n e q om N`。共同条件为 `1<N`、`0≤(data e q om).e`、`w≤N^(53/13824)`、`N^mu≤z≤cap` 和原 `FilteredSourceSupply s r n e q om`。在原 schedule 上，先给正的 source、box、sixth 三项容差，取共同的 `s,r,e0`，对 `0<e<e0` 依次用 `∃q0 ∀q≥q0 ∀om≤1/100 ∃n0 ∀n≥n0 ∃m0 ∀m≥m0`。三个原遗漏界与同一 source supply 保留。每次应用的目标、测试和模数使用上述一次选择。[原共同参数](https://github.com/UyNewNas/goldbach-formalization/blob/a023ae055d3d90738f6965a2848266aa13089faf/docs/source-only/20261104-full87-licensed-sixth/P4AOriginalFull87LicensedSixthRealization.lean)

* **第八层之前。** 原 `actual_stopped_difference_eq_shared_four_suffix` 将两侧的共同浅层精确相消。真第四前沿的每个已准第五 take 都满足 `B5*p5²<N^(299/500)`，其中 `B5` 已包含 `p5`。在进第八层前，剩余最多两个素数，且各自不超过 `p5`。对停止叶符号所选的非零 `betaPlus` 或 `betaMinus`，原 Rosser 活跃性给 `a<N^epsilon`。因此每个这样的完整乘积严格小于 `N^(599/1000)`。第四层的 skip 沿同一个递减素数表继续，两侧采取的第五门可以不同。该推导同时覆盖两侧都接受第五门的情形。[共同第四前沿的精确恒等式](https://github.com/UyNewNas/goldbach-formalization/blob/a023ae055d3d90738f6965a2848266aa13089faf/docs/source-only/20261108-full87-rank4-stopped-localization/P4AOriginalFull87RankFourStoppedLocalization.lean#L157) · [固定指数的预八层](P4AOriginalFull87Fixed599Stopped.lean)
* **第八层与后继。** 原 raw 的 `raw_live_full_modulus_lt` 已给出 `a*b<N^(epsilon+299/500)`。原 licensed 的 `actual_all_eighth_frontier_terminal_product_lt_fixed_power` 已对它自己的实际前沿、owner 及 retained leaf 给出 `b<N^(299/500)`。在该叶的活跃小系数上乘以 `a<N^epsilon` 即得同一严格界。由 `epsilon≤1/1000` 得 `epsilon+299/500≤599/1000`。原 `pairedCopies` 和 `firstDisagreementLeaves` 按 side、每次出现和原重数归位，随后逐叶消去 `leafHighQCharge` 中每个绝对费用。[原 licensed 粗积，第 157 行](https://github.com/UyNewNas/goldbach-formalization/blob/a023ae055d3d90738f6965a2848266aa13089faf/docs/source-only/20261112-full87-all-eighth-frontier-terminal/P4AOriginalFull87AllEighthFrontierTerminal.lean#L157) · [活跃乘积与绝对叶费用](P4AOriginalFull87Fixed599Charges.lean)
* **完整模数。** 原高区测试采用严格整数条件 `X<a*b`。若 `N^(599/1000)≤↑(X+1)`，每个上述活跃乘积都满足 `a*b≤X`。设 `d≥N^(599/1000)`，于是 `d>0`，取 `X=d-1`。此时 `highQTest X (qProbe d)` 等于原 `positiveQProbe d`。两侧分别使用原 `physical_positive_probe_eq_supported_rho` 读回有限总和。在每侧自身有限支撑外，原卷积系数按 `smallRoughRho_eq_zero_of_not_mem` 为零，得到 `highq_same_actual_rho`。这也给出原 `X≥N^(599/1000)` 的全部测试。[原完整系数读取，第 50–63 行](https://github.com/UyNewNas/goldbach-formalization/blob/a023ae055d3d90738f6965a2848266aa13089faf/docs/source-only/20261109-full87-full-rho-q-bridge/P4AOriginalFull87FullRhoQBridge.lean#L50) · [卷积支撑外为零，第 133 行](https://github.com/UyNewNas/goldbach-formalization/blob/a023ae055d3d90738f6965a2848266aa13089faf/ImbalancedChen/SmallRoughAttachment.lean#L133)

## 尚需完成的原稿职责
