# 两张原 HB 分支表在小模数上的有符号估计

**源级裁定。** 五份选定源码给出 `P4BOriginalTwoAtlasSmallPayment.eventually_two_atlas_small_and_remainder` 的两个同时结论。用 Q₀ 表示完整模数中 d ≤ N^(1/5) 的子集，Q₁ 表示余集。D(S) 是原双素数权在 S 上的同余计数减互素均值，H(S) 是原 medium 与 no-medium 两张分支表在 S 上的有符号和。每个自然数 A 和 δ > 0 都有 ‖H(Q₀)‖ ≤ δN/log(N)^A 以及 ‖D(Q) − H(Q₁)‖ ≤ δN/log(N)^A。计数接口可以直接用第二式。

**物理参数。** 固定 K ≥ 2、b > 0、κ > 0 后，N 门槛先于合法外宽及定理量化的所有矩形参数。对非零实际系数的严格 599/1000 支撑是假设，同一次 Fine 选取已给出该支撑。筛选 d ≤ N^(1/5) 读取包括小素数因子的完整模数。选定的 presieve 层指数小于 1/1000 时，原小素数与粗因子分解对两种 β 符号给出所有粗秩零、一都在 Q₀ 内。更高秩的实际小模数也在 Q₀ 中。

**算术核对。** 原有序双素数按较小素数 p 归属。正向用 p ≤ j，反向用 p < j，平方只计一次。固定 p，余下的自由素数权含四个物理仿射门、实际乘积截断与归属门。在自由坐标上每项各自单调或反单调、取值在 [0,1]。乘积变差 ≤ 6，加 Abel 末项 ≤ 7。当 p 与 d 不互素，因 d 与 N 互素，原同余行及互素均值都为零。可逆时自由素数取真实既约剩余类 N/p mod d。

真实支撑给 pj ≤ eN、p² ≤ eN。每个 p 用实际自由长度 Xₚ = min(N, ceil(eN/p))，其下界为 √N，故 d ≤ N^(1/5) ≤ Xₚ^(9/20)。ΣXₚ ≤ 2eN(1+log N)。在 A+2 的精度调用原 prime BV，再求和两个方向，已吸收完整 p 族。权的端点、既约剩余类及绝对系数条件都在原 BV 接口范围内。

**原表连接。** 子集仅限制最外层的模数。原 dyadic 双标签、HB 行及其标量、互素均值和真幂项负号均保留。两张原表的逐子集恒等式沿用原 rough-prime 零项。真幂误差的绝对界对任意 S ⊆ Q 重新由实际逐行费用和整数词重数导出。乘积恰为 N 的分支仍使用 τ(N)² 和真实非零模数支撑；这里没有使用全 Q 有符号和对任意子集的单调性。最后 D(Q) = D(Q₀)+D(Q₁)，小模数 D 与相应子集的真幂各用 δ/2。源结论控制两分支的共同有符号和。
