# 原 Γ9–21 全族的径向墙费用

已冻结的 fixed-box 七源给出 J 和原种子价。本补件给出真整数乘积在 M=N 附近的绝对费用，并把原 sharp 正负测试按实际素数位数精确送入 Part3 的 labelledPrimeTuples。四个 Lean 源只作静态交付，未执行本地证明、守卫或数值核验。

**原生双端点。** 在原正宽经典夹持区间中，R=N^ν/p≥N^(7/128)，新指定素数满足 q≥R^(50/227)，外 p≥N^(833/2500)。每个规范尾素数至少是指定的倒数第二素数。因此所有真实位点至少 N^(1/90)。若实际光滑外权在低端保留一个等于 1 的截断并在 N^(1/90)/2 以下置零，则其整数支撑最终至少 N^(1/96)。这是从原数值几何推得的余量。

令 z=N^(1/96)。对任意固定 c>0，最终 z≤cN≤z^100。原生 roughCount_buchstab_band_100 给出绝对误差，常数独立于这次查询。其归一化误差受常数乘 96(c·buchstabRemainder(z)+z/N) 控制，趋零。log(cN)/log z→96，Buchstab 函数在 96 连续，故
(log N/N) Φ(cN,z)→96cω(96)。
于是 bN<M≤cN 的真粗整数壳的归一化极限是 96(c−b)ω(96)。这个相减使用同一 z 上的两个双侧绝对误差。它不要求实际原种子全部 X_N 的双侧极限。用 (1−2h)N<M≤(1+2h)N 覆盖原闭墙 [(1−h)N,(1+h)N]，真实整数下端保留在覆盖内。

**整标记。** 每个候选秩 k 取所有 k 维有序素数向量，坐标 ≤2N、至少 z、完整 M 在该径向壳。2N 只给明确定义在 Lean 中的环境向量加坐标上界。目标仍是 N。对固定真实 M，原 p5z_marked_prime_product_fibre_card_le 给出至多 k^k 种完整有序向量，允许重复素因子。以 20∑_{k=0}^{200} k^k 为预先固定常数，可一次支付任意秩、20 个原字、权重每字至多 1 的外壳。若测定整个光滑函数，则应按原有固定幅值再分配预算。每个 ε>0 可预选 0<h≤1/8 使整壳的普通质量最终 ≤ε N/log N。大常数只决定选择的 h。

**回到原对象。** native_rank_count 在每个原字的 0..200 秩分解中保留 p、全部指定 q 和规范尾 r；同一字内完整坐标可恢复 p、q、m。原字列表在秩分解外求和，112、122 的双份保留。Part3.labelledProduct 与原 M 精确相等，测试依然是 M<N 且 N−M 为素数。原 sharp 支撑上 M≤N；用于向外过渡的有限环境取 Fin(2N+1)。对仅接受 Fin(N+1) 的后端快捷定理，原 sharp 域的每个实际坐标均 ≤N，可收缩该环境。光滑域允许跨过 M=N，原测试不会随环境改变。

RadialSeedCredit.original_boundary_le 把原实际闭墙逐字放进整条环境壳。ambient_boundary_price 给出先选 h，随后对所有原允许的 n、τ，最终
K₀ (𝒞(N)/log N) · boundaryCount ≤ ε Θ_clamp。
证明复用原 uniform_clamp_witness 与 sourceMassScale_mul_densityScale。这里支付的是原普通质量在密度尺度的绝对费用。对壳上的加性素数计数还须应用同一 ρ 的原正分布定理。geometric_raw_J 中的一次 ε 与选择径向 h 采用不同预算。当前包没有再次扣取 Γ5、全20小乘积或直接证明 measured PP。

**仍待承担的作用。** 原稿 prime-product-radial-boundary-repair.tex 把纯总乘积墙与非恒定仿射墙分开，薄 y 区间另有粗上界。本补件只覆盖临界 M=N 的上下两侧，并给出实际源的完整秩表示及低端过渡余量。原外 p、颜色、位次与尾序等非径向面在光滑外逼近时的无权质量、实际全族光滑算子与其混合导数、随后所有查询的一组同 ρ 谱/F 判据仍需各自供应。原 near-N 加性素数上界、ordinary seed 余项、四轮完整反馈以及 430+11 不由此取得。
