# 已付 Γ5 在夹持段 Eₚ+Sₚ 下界中的位置

取原 U3 夹持素数区间 [833/2500,1/3)。对先固定的 0<τ≤1/12 及 ε>0，所有足够大的偶数 N、所有满足 1/(n+1)≤11/384 的冻结精度 n 上，`original_clamp_credit_after_Gamma5` 给出

```text
5(Θ_clamp − Σ_p(E_p+S_p))
   ≤ Σ_p[其余原种子项 + (681/100)/4 · thetaConversion(N,p) · Γ5坏角未试整数质量]
     + ε Θ_clamp .
```

在左侧，Eₚ 与 Sₚ 保持同一真实 Q 的立方截点，分别计 Rosser 余量与最小素因子壳。在右侧，Γ5坏角原来的正素数计数已被支付。其余项明确展开为 Γ1 的 4∶1 两锚，Γ2–4 三个带负号的单素数母项，四个好对子，Γ9–21 全部长词及原碰撞、中心和母式误差。`otherSeedTerms` 只依赖这些整数计数和原选择器。

这里直接在真正的 p 根使用五倍母式。由于 Q/p≤N^(1/2−833/2500)，原种子截点 (Q/p)^(5/11)≤N^(417/5000)，每个原幸存商进入种子上筛。此前两项的真实普通近似给 5 倍误差中的 ε/2，已付 Γ5 占另外 ε/2。该下界保留显式余额；尚无结论将其变成任何指定正比例的 Θ，H430 以及其他种子责任仍开放。本源码作静态交付，未经 Lean 或 CI 编译。
