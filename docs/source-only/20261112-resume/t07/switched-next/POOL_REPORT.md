# 原正 Γ5 的全模数合并

在首组三份源码上增加两份。对任意固定 0<τ≤1/12 和 ε>0，取足够大偶数 N。门槛先于 n，满足 1/(n+1)≤11/384 的全部 n 同时有效。对原经典段任意子集 B，`actual_Gamma5_at_common_mass` 给出

```text
Σ_{p∈B} [ max(originalBadPairCount(p),badFibre(true,p))
          − (681/100)/4 · thetaConversion(N,p) · badFibre(false,p) ]
    ≤ ε Θ_clamp .
```

上式的有符号差允许不同标签补偿；没有对正部逐行取和。选 B 为原结构夹持段，右侧恰是本族的 εΘ。选 B 为全经典段时，右侧也受本族 εΘ 控制。非空变化小盒仍只得到同一个全池绝对预算。此项在第二种子的五倍不等式右侧以正号出现，因此该母项和同载体测试均可按原价核算。

`actual_bad_whole_pool` 展开真上 Rosser 系数。若系数非零，即有 k=pab·r≤Q≤N^(1/2−τ) 且 k 与 N 互素。配对使用原半开素数窗和 p·a²b≥Q 的离散拒绝条件。三个标签均是 k 的至少 N^(1/200) 的素因子；每个 k 的外 p 和两个有序内素数的选择数至多 200³，随后 r 唯一。中心素数整除 N。除去这批中心的额外每行费用由 k=pab 单独装入同一合并，用 2·200³ 作固定上界。原素数分布、字面 li 与真 li 平移和已删除中心在同一完整模数展开；一次绝对 BV 及 N^(1/2)log N 的校正给 Oτ(N/log³N)。上轮真实夹持质量的统一正下界将它吸收。

由此，先前 REGISTRY 中列为尚待形式合并的一项已有这两份源候选。原四个好对子、三个负单素数及两个锚、Γ9–21 正源、四轮及后续前代均仍在各自原责任上。这里没有足以单独推出 H430 净增益或 E_p+S_p 完整平均下界的估计。源未经 Lean 或 CI 编译。
