本复核只登记源码支持的窄命题。各根项保留自己的见证、掩码、所有者及物理 Q；需要同 Q 的是在同一个非负标记母族中，不是强制所有根标签具有同一个物理值。正文 795–817、857–895 和 lower completion §§3–4 的 430 表只由 U3/U4 使用，另九项没有替换。11 是并列标记的根/叶项；441 是传播预算，不是把十一项做成十一轮 H430 更新。原输入顺序是 reserve → δ → 固定有限细化/正 τ/各前缀 cap → N₀ → 所有 N≥N₀。

1. **公共光滑图。** 带边距的 [-1,2] 一维网格在整个 [0,1]（含 0/1）上非负，标签和为 1，单个支撑的物理直径小于 4/(m+1)。对不同精度取非负乘积，沿有标记的左右 factor 地址边缘化，严格恢复被选择的旧一维测试。张量只按原生逐槽相乘，给未来槽位求和严格还原旧前缀，零槽不制造额外素数。并列查询可以使用同一有限计划；重合的根标签仍按地址区分。这里是重叠的光滑单位分解，不是不交算术格；没有靠分别选 N/mesh 或不受证据支持的上界单调性拼接选项。
2. **原生查询。** 对每一原生形状、正/反方向、全部 401 个（含单点）表原子，固定计划上的 hit/sure/mixed 给出可微上下界；差精确为 mixed 标签权。取过的点实际共享同一格，且每个坐标相距小于给定直径。原配置直接使用 frozenRoot、canonical nativeProgram 及 QueryMember；生成位置通过 rootHistory_member、rootHistory_realization 及 exact native tuple/code 对接，而不是准许任意整数为 Member。固定 RootKey 的 frozen-root code、430 原 owner、真 clamp 位及累计 argument codes 与 keyAt 四项逐一相符；新 ownedQuery 用同一 tuple 同时核原 program、read mode、实际代的 candidate 以及 terminal atom。仅对 generated rootHistory 成员给出此等价。emitted_native_prefix_marginal 直接将 native slot 按祖先步号分成 past/future，在同一元组上对 future 求和；单素数边与零槽保持真实 arity。双素数原坐标为 [small,large]，整数词 appendedWord 为 [large,small]；成对的公理化坐标相同没有被使用。在原生槽位直接 splitNative 处理读数，不把两个序的固定标签无条件等同。
3. **前缀、候选和楼层。** ChosenPath 按原 fuel 拆分旧前缀/未来，不重新选择候选；位置的 Q 源自 frozen root，同位置的输入表为原 g。对同一位置、同一非负 mark 光滑拆分后重求和，严格恢复选中 bank 的 base、原 Q80 取整损失、有符号的 Θ−1 修正。不存在“signed correction 取零”或“单个算术 source 假设全家族”的步骤。这三个是精确等式，数值承付和闭 cell 归纳仍另需。
4. **十一项真正计数。** 原 p5MarkedElevenSource 中的标签、加法素数与 tuple 未变。按其真实零/一/二/四槽取坐标，无 padding/additive-prime 新槽；六和十一项沿用同一 E。原根整数账本的权重绝对值和为 14，全部除 4 后与 rootCoefficient 逐标签相同，故原范数 7/2；实际带符号求和复得 currentChenPairedPrimeSum/4。U3/U4 使用同一个原 p 的单槽证明不是对所有子计数的等式。
5. **父权整行的定量。** 两个历史供应者本已对所有位置一致；银行行的 floor 和真 α 来自 rootHistory_support。固定同一位置的非负原生父格标记乘逐位置的绝对误差估计，max(T_bank,T_Buchstab) 先于 N 和随 N 变化的 Index。对实际胜出的 bank/Buchstab 分别为 12/5 的 Θ 行质量上界，wΘ=0 时先作绝对零结论再谈除法。该估计是整行乘父权，不是先拆原行子格后逐子格绝对值之和。保留及其它分支不能由此充作有误差承付的 bank 赢家。
6. **原生子素数。** 在真正新素数的物理坐标 L·u 乘上预先固定的图标签，而不是只给旧父位置乘标记。换到 physical x 后联合测试 dilationKernel(L,f,x)·atom(x) 对正紧残差参数与所有紧启动参数连续且有界；重装盒的 prime sum 和 integral 使用同一个变量代换。trueSingleTest_error 保留 localPrimeFactor；有限 BIndex=两方向×401 atoms×所有一槽图标签，每项先分 δ/(card+1)，后以 finite eventually_all 取统一 N₀，因而绝对误差总和 ≤δ。这段本身到 trueSingleTest 的 N 窗口。下一模块确实进一步回到 d·N 与严格 Buchstab 窗：绝对有界的 child mask 可用既有 prefix-mask difference；逐 q 的真实 Θ 插入和归一核给出闭窗等式；应用有符号 ceiling-fibre 费用 ≤(4/A)Θ（选 A=max(4,8/e)），识别严格 singleChildren。选择请求的真 guard 推出 1≤s；剩余高度用真残差 floor。对固定图的所有子标签及 401 原子先取绝对值，再以同一 g 的 immutable precedingH/h 绝对值加权，e=δ/((M+1)(immutable430AtomL1+1))，求和 ≤δΘ。这里按真实 d·N 的互素窗口保留 prefix 删除。
7. **可用与未用的共同阈值。** 原 reserve 的 δ 以 (7/2)δ(12^441−1)/11 支付的标量选择是旧 reserve lemma；选择同一正精度几何图再把已限定供应的统一阈值取最大是有效的。reserve_common 明确在选定 m 后由 max(Tp,Tc) 同时给 FeedbackAt 和 StrictAt。两个误差各自小于等于 δ 时不能因此把它们相加仍收费 δ；精细项应替代相应整行项，或另行分配。不能按随 N 增长的位置数取有限阈值的最大值，也不能把几何直径或 Θ 正性当作未知 mixed/child/base/leaf 相对误差。
8. **书面 N_geom 的范围。** 固定合法 n、τ、原程序和根 mesh 后，读点、比较和有限表格选项分成有限片，保留恒等墙的原真值。混合盒的异值点给出 cube 内通往相对边界的线段；对该有限族，非恒等多项式的零集及网格端面体积为零。在实际激活的素数指数≥b>0 的紧盒上，先取细图并取矩形外包。对充分大偶数 N、真实 owned root 与 admissible emitted path，T23 的逐词 Θ/H(N) 对调和素数乘积的有界支配、bound mark≤1，以及固定根/形状/有序有效 prime tuple 的位点至多一次，可使这些格的**外归一绝对**代价同时小。唯一性来自每个请求只解析一个 winner、retain 一条、各 W2 component 用不同 shape、每个 prime/pair Finset.toList 无重；并非泛称一个 product 或 catalog label 只有一条路径。此项是两份书面证明的范围性复核，非 Lean 终端或任意 root/receiver 子族相对其自身 Θ 的估计。
