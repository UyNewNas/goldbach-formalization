canonical index/source ID **1**. All four Lean files are **source only and
uncompiled**. The Python measurements and consistency checks confer no parse,

## Reuse and validation

`generate_direct.py` adapts the existing generator published at
`4b7aaff36b55a7c7098fb6abf0e8f51a47efa948`.
`generate_typed_payload.py` adapts the existing generator published at
`55ef1e4be9d8295ab5ced1335f1210f52a7031b2`.
Both load the unchanged donor `Node`, `Field`, `RawPlanner`, `quote_char`,
`quote_list` and `lean_node` definitions, bound by their original SHA256.
The typed generator's nine original helper ASTs remain identical. The complete
Python delta is retained in `GENERATOR_DELTA.patch`.

The read-only `check_candidates.py` audit binds generated bytes to both
manifests, checks all 2,496 typed scalar locations against the exact original
strings, checks the raw field spans and all 81 row names, and reconstructs both
thin transports from the pinned original templates. Its output is
`HOST_CONSISTENCY.json`. The original generator records declaration emission
order while serializing scalar definitions before data definitions; the audit
checks the exact complete unique name set, rather than equating those two
different orders. No Lean or old accepted test suite was executed.

Generation is immutable: an existing output must match byte-for-byte. To
reproduce from an already available original witness:

```bash
python -B measure_input.py --input /path/to/existing/eighth-prefix-family-20261009-cell-01.witness.json
python -B generate_direct.py --input /path/to/existing/eighth-prefix-family-20261009-cell-01.witness.json
python -B generate_typed_payload.py --input /path/to/existing/eighth-prefix-family-20261009-cell-01.witness.json
python -B check_candidates.py --input /path/to/existing/eighth-prefix-family-20261009-cell-01.witness.json
```

Only this exact Cell01 hash is accepted. These commands do not download input,
invoke Lean, edit production sources or generate the other thirteen cells.
