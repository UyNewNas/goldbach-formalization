## 新文件二：O/P 现有同 rho 的 J0 与完整实际支持

`P4AHeldTaggedCompilerSupport.lean` 始终使用

```
P4ACommonPolicyTaggedCompiler.compiledRho data N cap w z tau L
```

及其原 `heldRetain`、`historicalTag`、`compiledCoefficient`。没有重新定义一个方便的 rho、独立 beta pair、额外粗支撑谓词或 arbitrary CapPlan。

`J0 omega = ceil((599/1000)/omega)+3` 在 N、枚举 cap、fine atoms 之前固定；`J0_spec` 给原稿所需严格 `J0>theta*/omega+2`。`held_raw_rank_lt_J0` 使用真正 rough support 的每个素因子至少 `N^omega`、squarefree product 恒等式以及既有实际 `<N^(299/500)` 支撑推导 rank。不是对整个粗除数 universe 假设一个 cap。

`held_outer_rank_lt_J0`、`held_crossing_rank_lt_J0` 从 O 真正 outer/crossing 的 retained witness 和同格 label 长度得到相同 rank；不需要给定 mixed-wall cover。它们包括被收费点自身，而不是只给 witness 的 rank。

`same_cell_product_le` 从两个真实 half-open prime-label 列表相等逐项推出 `p<=N^tau*q`，再沿原 canonical prime subword 乘回，得到被收费 d 本身的

```
d <= N^(tau * rank(d)) * e.
```

这里 e 是 O 实际同格 retained witness。`held_compiled_rough_lt` 由此得到每个非零 actual compiled rough coefficient 的 `rank<J0` 和 `d<N^(299/500+tau*J0)`；short/inherit/unit 的原支撑已由复用供应覆盖。

`held_compiledRho_nonzero_factors` 从 **同一** O `rho_at_product` 取得唯一类型 small/rough factors。实际 compiled rough coefficient 的符号决定 plus/minus beta，非零 beta 给真正 `a<L`。`held_compiledRho_support` 因而在唯一总预算

```
ell + tau*J0 < 1/1000
```

下推出原 **compiledRho** 的每个非零 q 都 `<N^(599/1000)`。没有把 beta 和 box 各花一次完整 `1/1000`，没有对 displayed carrier 中的零系数行声称支撑界。

`exists_preN_held_compiled_support` 真实选择

```
tau0 = (1/1000 - ell) / (2*(J0+1)) > 0
```

后，对每个后来 `0<tau<=tau0`、所有 data 且 `data.e>=0`、N>=2、枚举 cap、z 和非零 q 同时成立。原 beta 参数可代入 `omega=nu*epsilon^2`、`ell=nu*epsilon`；本结论不消费 density 或 compiler 的数值 reserve。

**边界：** 这是 O/P 已有 held constructor 的完全实际支撑转换。E 的 source header 和 O 的定义仍表明其六阶只有十一源域，八阶 guard 是 `PhysicalRows` 存在式；新支持 theorem 没有证明这等于原完整87的历史。它也不证明 full selected-complement factorization、post-loss PP cover 或 upper PP。
