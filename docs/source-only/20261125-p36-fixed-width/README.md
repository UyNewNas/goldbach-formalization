# warm cap 的固定宽度墙带预留

状态：**仅源码候选，未编译、未 kernel 验收**。本目录不改变当前选中源码清单。

1106 稿件要求先冻结有限策略，再选一次有限细分，随后才让 `N` 增大。实际 pair-root 的 incoming cap 可以依赖外部素数对和 `N`。此前的 `P1ActualMovingAffineSlab` 已证明任意中心的量化估计，并给出宽度随 `N` 趋零的结果；后者本身还不是一次固定细分所需的量词。

本候选直接调用已有量化估计，补出：给定正误差，存在正的固定宽度和一个共同阈值，使所有更大的 `N`、所有实中心的实际素数墙带质量均小于误差。其中心量词位于宽度和阈值之后。

## 复用与新增推导

旧 `affineSlabMass_le_envelope` 已完成真正的素数坐标分解、原目标整除删除、剩余坐标求和以及闭端点素数原子的支付。此处完整复用它。

设剩余坐标素数盒质量的极限为 `tailLimit`，取 `C = |tailLimit| + 1`，因而在共同阈值之后该质量小于 `C`。若选中的非零系数为 `v j`，取

`delta = eta * |v j| * a j / (8 * C)`。

旧标量 envelope 的宽度项于是精确等于 `eta / (4 * C)`。其余项就是旧的零宽度 envelope，随 `N` 趋零；统一压到另一个 `eta / (4 * C)` 后，再乘真正的剩余坐标质量即可支付误差。没有新数论估计，也没有把缩小网格当作固定网格。
