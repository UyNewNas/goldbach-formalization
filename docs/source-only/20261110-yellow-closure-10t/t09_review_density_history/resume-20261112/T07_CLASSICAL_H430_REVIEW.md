# 经典 U3 的实际 Θ 与第 430 代上表余额

**静态源码裁定。** 五个选定模块给出原 U3 经典段 [57/224,1/3) 及其正宽子段 [833/2500,1/3) 上的同 Q 普通估计。设 Cₚ 是在原 N^a 处计数的真实整数商，Eₚ 是立方截断处的 Rosser 多项式余量，Sₚ 是此处到 N^a 的首素数壳计数，θₚ 是原权 4 li(N) C(pN)/(φ(p) log(Q/p))。对任意先固定的 0 < τ ≤ 1/12 与 ε > 0，足够大偶数 N 上，所有 1/(n+1) ≤ 11/384 的 n 同时满足 Σ|Cₚ+Eₚ+Sₚ−θₚ| ≤ εΘ。两个区间各自用自己的 Θ。实际最终 H430 上界仍需对 Eₚ+Sₚ 的总额给出下界。

**相对误差的分母。** 原物理素数 p 不整除 N，经典段所有 p 使用共同 Q = N^frozenLevel(n,1/2−τ)。由真实非空宽区间的半层原极限、θₚ 对 Q 的单调性，可在实际 Q 得到 Θ_clamp ≥ 4 log(834/833) H_N。全经典质量由包含关系更大。前次已审完整模数 p·r 上的 BV 估计，在固定 τ 后给全经典 Σ|signedAPₚ| = Oτ(N/log³N)，一次吸收到该正宽区间 εΘ_clamp。因此对每个区域给出单独估计，未要求给每个变化细格一个质量下界。空类上的实际 Θ 与计数都为零；非空类的严格正性不能保证上述相对误差对该类成立。

**同一 p 的普通主项。** 原参数 s 在 [2,149/50] 内，一侧网格读数 w 满足 s ≤ w ≤ 3，两者的普通幅都为 1。真正筛目标 M=pN，β=log(Q/p)/log(pN)，其中 11/768 ≤ β ≤ 1；在紧参数 (β, β/w) 上使用原双侧 Rosser 普通均值。M ≥ N，N 偶时 M 偶，阈值统一。原 p 不整除 N 使规约的有理幂 Q/p 不是整数，故 ceil(Q/p)=floor(Q/p)+1；筛系数、严格切口与原均值相配。4/β 归一化后恢复上述 θₚ，绝对偏差逐 p ≤ εθₚ。中间半层比较未更换该算术主项的实际 Q。

**两个接收对象。** 真外素数 p 标记模数，接收素数是 ℓ，商为 (N−ℓ)/p。原 Cₚ 对应筛到 N^a 的整数商。在一个旧 owner 类上，辅助 markedPhi(w) 等于 Σ(Cₚ+Sₚ(w))。在同一 w 查询上比较此标记族时，壳已经进入左端，只能再用 Eₚ(w) 作改进额。对原 Cₚ 的估计则可用 Eₚ(w)+Sₚ(w)。原上多项式的逐系数首立方恒等连同有符号的完整模数测试，给出 Eₚ(w)+Sₚ(w)=Eₚ(3)+Sₚ(3)，独立于辅助网格索引 m。

**实际 H430 的未付估计。** 对原 Cₚ，夹持段的剩余为 H430(2)·Θ_clamp − Σ(Eₚ+Sₚ)，已经隔离出任意小的相对误差。原数组两个相邻条目的系数均为 37052565421922458792801/2^80。实际第 430 代选择器的增益在夹持段还可由原种子逐代保留得 ≥ 1/50。这两种正价各自成立。真实整数余量的非负性不能支付任何一个正主阶；仍需在原族上证明有方向的平均下界。全经典段的同类余项按原 sₚ 读取各自 H430(sₚ)。一个子段的正费用并不判伪全段或全稿。经典 p 有 p²>N^(1/2)，不能把 p 直接塞入旧 Wu 窗并同时满足该窗所需的前缀乘积乘 Vⱼ² 上界。增强段、真实前代及 W1/W2 行、430+11 转移的物理输入仍需单独支付。整黄职责维持。
