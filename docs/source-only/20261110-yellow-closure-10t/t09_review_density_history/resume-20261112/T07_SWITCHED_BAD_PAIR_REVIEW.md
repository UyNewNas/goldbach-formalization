# 经典 U3 根上原 Γ5 拒绝区的逐素数对上界

**源级裁定。** 三份源码给出原第二种子中一个正项的逐标签上界。令 p 属于足够大偶数 N 的原经典 U3 段，Q 是该根的冻结总层。令 a<b 为两个原半开窗素数且 pa²b≥Q，D=pab，y=(Q/p)^(50/227)，w=(Q/D)^(1/2)。原未净化 Γ5 母项和原测试素数质量的最大值，减去 (681/100)/4 倍同 p 转换因子与原未测试质量之积，至多为 signedAP(N,D,Q,w)+#primeFactors(N)。右端保留原模数 D·r 的有符号误差。终端没有以 H430、前代换算或所需 switched 估计为假设。

**几何与整数载体。** 拒绝壁的等号保留，两个素数实际位于 [(Q/p)^(50/227),(Q/p)^(10/29))。从原 badLabels、p 的半层、1/(n+1)≤11/384 和 0≤τ≤1/12 推出父剩余指数至少 7/128，子对数分母至少父对数的 9/29。拒绝壁和顺序给子分母至多父对数的 1/3。因此 N^(1/200)≤w≤y，且 x=N/D 满足 2≤log(x)/log(y)≤100。原两种质量都从同一组 1≤m≤x、最小素因子≥y 的整数取值，包括单位。测试额外要求 Dm<N 且 N−Dm 为素数。原母项保留自己的 pN 掩码；借 w≤y 和 pN∣DN，互素接收素数可嵌入同 Q、较小切口 w 的冻结上筛载体。删去中心的候选接收素数属于 N 的素因子。

**普通主项。** 原 Buchstab 一致定理与 ω(u)≥1/2 对实际 y 给未测基数 ≥(49/100)x/log(y)。原 θ 转换使其主尺度精确成为 (227/50)θₚ/(ab)。实际两素数各自的局部因子最终至多 (101/100)/素数，故 θ_D≤(10/3)θₚ/(ab)。在 w 处普通参数正好为 2，上幅为 1。用相同 Q 的真实普通 Rosser 估计及原 681/100 常数的有理不等式就能支付该模型。原有限 Rosser 余量非负，带符号完整模数误差仍原样进入上界。共同 N 门槛先于之后的原 p,n,τ 和所有坏标签。
