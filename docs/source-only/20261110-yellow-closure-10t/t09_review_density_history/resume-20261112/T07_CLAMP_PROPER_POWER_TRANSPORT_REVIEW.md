# 原经典 U3 夹持族的真素数幂与截断费用

**源码范围通过，七个选本、22 项声明。** 对原 Γ9–21 的 20 个标记词出现及所有有序尾秩，`selected_rough_atlas` 把原未截真素数的带号误差接到原粗 Λ/log 全组 HB 和。原相对价格为 switchCost·Θ_clamp，附加误差可取任意 ε·Θ_clamp，终端仍含 Re(roughAtlas)。实际分析用固定最大秩 200，逐原秩、逐原图结算。

1. **标记、秩和系数。** 同秩整数权为所有属于该秩的 lane 之和。单个原出现的外权属于 [0,1]，实际聚合权由独立于 N 的 Fintype.card Occurrence 控制。重复素数和同值词的不同出现保留。0 至 3 阶权恒为零。完整 Q 中可有任意大的零权模数。exists_row_costs 的前提为 Q 中每个 d 为正、全域 |ρ(d)|≤1 及仅非零 ρ 满足 d<N^(599/1000)。后两项由原 tagged coefficient 和 Fine 的同一组支撑给出。

2. **非对角和对角。** 在 M≠N 的非零图上，有 1≤M≤2N。保留同余计数和原互素中心后，完整 signedRow 的范数至多 C N^s。该界适用于 N 两侧。原 properChartWords 的一个坏坐标是整数 n=p^e，e≥2；物理下限约束 n，原有序真幂计数对所有可能底素 p 取和。每个图自己的 roughWord 等于作用于完整 M 的 roughOneSlot，绝对值至多一。取 s=1/720，原幂数目界和全部图给 N^(1−1/180+s) log(N)^201。M=N 时保留减去 1_coprime/φ(d) 的整个对角行，并按 τ(N)^k 计有序乘积纤维。所有图的总对角界为常数乘 N^(599/1000+2s) log(N)^200。两界分别有固定幂余量。对有多个坏位的词，原恒等使用真幂词的并集，绝对上界允许对坏位计重。

3. **粗筛及 η。** 活动真素数坐标 p 至少为 N^(1/90)/2。将原 before-HB 截止定理应用于独立 cap 2N 及指数 1/192，利用 (2N)^(1/192)≤N^(1/96) 及原 transition_floor，得到每个非零真素图上所有 p 严格超过本图截止，roughPrimeReserve 为零。对固定 0<κ₀<1，原 η 未覆盖质量只出现在 M≤ceil(2N^(1−κ₀))，该上界最终严格小于目标 N。以 κ₀/4 分别吸收低词数和完整行的余量，201 个秩共用 N 阈值。独立字母 cap 一直为 2N，所有同余的移位始终为 N。

4. **价格与余项。** 未截素数误差减粗 HB 和恰为 trim 之和减 proper 之和。两个付款先统一于 singularNormalization N，再用原正宽固定区间 [833/2500,1/3] 的积分下界转为 Θ_clamp。对合法 root,t₀、0<κ≤1/112、固定 κ₀、ε,eMax，原 Fine 选择只作一次。其非零范围、HighAtoms、编译支出和密度均随同一个 β、k、D、R 保留。原正计数价与本次差额各用 ε/2。该比较针对整个原夹持族。
