# 原秩二符号和中真素数幂修正的独立审查

**三份证明源码可以进入安装清单。** 末份选用限定等式右端幂和展开的安装副本。结果付清原秩二物理轮廓的全部真素数幂修正，对阶数至少二的 HB 展开，截断后的有符号误差只余原 medium 与 no-medium 两个分支。两分支的分布估计仍待证明。

### 同一模数和与整数延拓

我核了原《distribution-prime-product-completion-20261010》§2、joint-audit 的素数幂段以及实际有限模数定义。这里的两个坐标有序，允许重复。每个原 chart 的费用含原始归一化 Λ、随标签而变的 rough projector、独立的乘积截断、物理轮廓的真实整数延拓，以及同余项减带互素条件的均值。模数集逐点是 `Q omega N`，系数是 `P4AOriginalFiniteFallbackPolicy.rho` 的原 bank、原参数与 aligned width。证明只复用旧源的倒数尾、距离除数界和碰撞词数，不依赖旧策略的系数结论。

`proper_chart_sum_le` 在粗糙性投影仍处于原位置时才取绝对值。原 χ 递减，ψ 非负，故每个原有序整数词上，整套 dyadic 标签的权重范数之和恰为一。没有按标签数量另收费用。有非零物理延拓的词满足两坐标均至少为 N^(19/96)，且它们的乘积至多为 exp(1)N。原 properChartWords 见证至少一个标记位置是 p^t，t≥2。两个位置同时命中时容许在上界中计两次。标记位置的倒数尾、另一个位置的调和和及乘积上限共同给出 O(N^(1−19/192) log³N) 个词。

### 乘积等于目标的独立费用

对 x≠N，实际同余行中的模数整除非零距离，真实均值用原非零模数集上的倒 φ 和控制。两项合计 O(N^ε)。对 x=N，由有序词到两个除数的单射得至多 τ(N)² 个词。Q 中零系数可删，实际非零模数严格小于 N^(599/1000)，故此处一行费用为 O(N^(599/1000+ε))。ε=(19/96)/4 使两个总幂指数 1−19/192+ε 与 599/1000+2ε 都小于一。两个费用各用 δ/2。未将非对角的词数乘以总模数水平。

`eventually_actual_proper` 对每个自然数 A、每个 δ>0 给出同一 N₀，随后才任取合法 b、κ、s、阶数、截断、最终策略及矩形参数。s>0、b>0、κ>0 和原宽度条件 2s≤baseline(b,κ)−19/96 仍在。原正模数与 |ρ|≤1 直接导出。唯一支撑前提正是同一次 Fine 选择对一切非零 ρ 已给的严格界。对全部标签的修正范数和至多为 δN/log(N)^A，甚至无需 N 为偶数。`eventually_trimmed_two_atlases` 对 K≥2 使用原精确负号、已证 roughPrime=0 及上述范数和。在同一真实 ρ 上得到 PP(V) 与全部 medium+noMedium 之和的距离界，原物理质量仍取未截断的 W。这个结果不含任一剩余分支的总和估计。
