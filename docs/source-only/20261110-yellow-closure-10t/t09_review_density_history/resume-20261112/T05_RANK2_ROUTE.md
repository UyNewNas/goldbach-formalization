# 原粗秩二的一组 dyadic 素数标签

此记录核对 T05 提出的路线，尚未验收其实现。原 prime-product completion §10 及 low-rank-convolution-bv §7 允许先在两个有序原素数上施用低秩卷积 BV，随后用同一算术量和原 HB 两分支表之间的逐标签恒等式恢复该项。

- 令 R 为不超过 √N 的最大二次幂。所选两个现成标签尺度为 R/32、R/4。原 ψ 的闭支撑分别给出 p₀∈[R/64,R/16]、p₁∈[R/8,R/2]。这是一对随 N 移动的有序标签；其余标签仍需各自的证明或可求和的统一估计。
- 固定 0<b<1、κ>0、κ₀>0 后，p₁≥p₀、p₀≥p₁^b，乘积介于 N 的两个固定正倍数之间且小于 N，最终同时超过 2N^(1−κ) 与 2N^(1−κ₀)。因而四个原上门及乘积 η 在这一个 ψ 支撑上均取 1。阈值可依赖 b、κ、κ₀，对满足这些条件的固定参数可以统一所有合法 s。
- 直接供应是 P2GammaPrimeLocalConductorSaving.exists_actual_prime_local_conductor_saving。按跨度二拆头端，primeSWInterval 为整点 Ioc，公共端点需一次归属。头系数含真实 ψ 与素数指示函数。删除参数 1 保留原全部素数，实际剩余类仍为 (N mod d)⁻¹。互补 ψ 素数行独立于模数及其剩余类。两个补零长度、两行 L²、互补 L¹、头的可导性与绝对 Abel 范数均需从实际区间推出。
- 从同一矩形取 d>N^(1/5) 与 activeLow 的交集。在原 ℓ<1/1000、同一非零系数的唯一小素数/粗分解下，这里只含此前未付的粗秩二。整模数 d<N^(2/5)。局部尺度 x 为完整两长度之积，在本图 x 与 N 相差固定倍数，故可取固定正 ε 使 d≤x^(1/2−ε)。两长度也都在 x 的正幂范围内。原实系数绝对值 ≤ 1、d 与 N 互素，原同余项与精确互素均值共用它。
- 单标签 HB 字典还需保留 rough-prime 零项及真幂费用。全标签有符号误差不能直接推出所选一项的绝对界。已有逐标签绝对费用总和，或其逐行一致版本，可以用于该子集。结论至多支付这一个标签的 medium+noMedium 联合和。

补零、端点和逐标签字典属于本路线的实现与连接。若把同 ρ 的卷积差或恢复总额直接作为前提，则算术付款仍待证明。对全部粗秩二，仍需支付其余标签上耦合物理权的分离及总恢复成本。现成局部导子定理已有真实数学源码。本记录没有新增证明或颜色变更。
