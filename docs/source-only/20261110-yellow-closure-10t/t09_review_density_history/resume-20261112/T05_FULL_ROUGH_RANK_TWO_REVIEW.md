# 全粗秩二的原有符号双素数付款

**裁定。** 已独审 T05 冻结的九份源码。前两份的有限振幅与恢复结论沿用先前独审。本次七份续源补齐实际算术付款。在 S = remaining(ω,N) ∩ activeLow 上，原标号双素数的带符号进度和减去精确互素均值，满足任意 δN/log(N)^A 上界。在同一 S 上，两张原 atlas 对 chartBank(N,2) 全部 js 的有符号联合和也满足该界。原稿 distribution-prime-product-completion §10 要求在 HB 分拆前先处理低粗秩，low-rank-convolution-bv §§1、7给出局部整模数的导子路线。本包的付款对象和先后顺序与两处相符。

**载体与原标号。** PrimeMesh.source_blocks 从 labelledPrimeTuples(2,N) 的两个有序坐标直接重索引，平方及互换坐标均保持原重数。每个首或次素数的 dyadic 所有人由 log₂(p−1) 决定，故 (P,min(N,2P)] 等整数半开窗互不重叠并完整覆盖。宏窗中的头素数以 stride=⌊P/J⌋+1 及截到末端的共同整数端点再分，允许空格。这里的整数双分组只用于证明双素数估计。原 HB 表打包通过此前已审的 eventually_subset_atlases，在同一 S 对全部原 js 恢复，无须把整数宏窗冒充某一个原 HB 标签。

**低乘积区。** x=PV≤N^(9/10) 时，共同门槛给每个真实算术乘积 1≤pt≤4PV<N，排除对角 pt=N。对应的 kernel_row 精确为同 S、同 c 的 signedRow。为满足既有 exists_row_costs 的全支撑条件，GlobalPayment 只在 S 外把 c 置零，并证明整个 S 内的 signedRow 求和值相等。S 中 d<N^(2/5)，所以该延拓同样满足原 599/1000 指数条件。取旧真实离对角幂界指数 1/50，两个原素数窗分别至多 P、V 项，且真实权绝对值至多 1，故每低宏窗费用至多 C N^(23/25)。这一步无需进一步收缩 κ₀、排除合法 s 或假定 prime-product 分布误差。

**高乘积区。** 每个高宏窗先在实际两素数中检查 W 非零，无活动点时原和为零。一个实际非零点已足以由原四门推出 2P、2V>N^(19/96) 和 x≤exp(1)N。在 x>N^(9/10) 区域，两轴最终 ≥x^(1/10)，全模数 d<N^(2/5)≤x^(9/20)，log x≥log(N)/2，且 J≤P。SampleConductor.exists_bound 调用原完整 prime-local 导子估计。唯一头权是常数 1 乘素数指示，删除参数是 1，实际进度目标是 N，字符坐标是 (N mod d)⁻¹。原定理对短至空的头窗也统一，互补行独立于 d。样本和非负振幅行均满足 |g|≤5，补零长度是 2P、2V，头平方能量 ≤2P，互补一范数 ≤10V、平方能量 ≤50V。S 的 d>0、(N,d)=1 与 |c(d)|≤1 均来自同一实际系数，而原非单位乘数仍按相同的进度和互素均值核计入。两次调用各沿同一模数集，系数分别为 c 与 |c|。

**短窗和全族费用。** 对同一 t 先用五因子端点振幅和至多 5，且 #I_i≤stride≤2P/J。全头窗恢复费用因此只有 20 M x/J，其中 M=Σ_{d∈S}|c(d)|/φ(d)≤4(1+log N)；两次导子费用合计 2J K₀ x/log(x)^D。目标 A 下先把每块精度定为 A′=A+2，选 B=A′+2、D=B+A′+1、J(N)=ceil(log(N)^B)。共同常数和充分大阈值先定，J 的数值随 N。两种块费用都能在给定常数下支付到 A′，每轴宏窗数 ≤bankLogConstant·log N，双窗总数与额外两次幂的对数相抵。对原目标作任意细的 s 选择不产生 s 的负幂费用。

**三个出口及原参数。**

- eventually_original_prime_rank_two 先固定 A 与 δ>0，再取共同 N₀。随后对全部 b>0、κ>0、s>0 且 2s≤baseline(b,κ)−19/96、任意实 κ₀，以及实际 m,r,n,e,q,a,ω,k、ℓ<1/1000，支付 S 上的原双素数差。该出口不需要外加全系数支撑估计。
- eventually_original_atlases_rank_two 与 eventually_only_higher_ranks 对固定 HB 阶 K≥2、b>0、κ>0、A、δ>0 先定 N₀，再统一于全部合法 s、实 κ₀、ζ和政策参数。原真幂恢复需要全体非零 c(d) 的 d<N^(599/1000) 支撑。实际 FineDensity 的同次 β,k 选择给 ω=νβ²、ℓ=νβ<1/1000 及此严格支撑。两源终端对选定参数直接适用。
- 写 D(U) 为实际素数差、H(U) 为两张原表在 U 的有符号联合和。先用各 δ/2 支付 D(S) 与 D(S)−H(S)，得 |H(S)| 上界。完整余式单独从原分拆开始，small 的 D、S 的 D、其余高集合 T 的 D(T)−H(T) 各用 δ/3，得到 |D(Q)−H(T)|≤δN/log(N)^A。T=remaining∖S。此前单标签的价包含在全族内，未累计到此预算。actual_rank_at_least_three 对 T 中每个非零实际系数及其原 small/rough 分解给粗秩≥3；非零项的分解存在性与唯一性见既有真实乘积支撑。
