# 全粗秩二双素数的五因子振幅和有限恢复

**独审范围。** GateVariation 与 PositiveRestoration 在各自有限结论上通过独立源码审查。第一份给出同一个整数头窗网格的逐伴随变量振幅和。第二份在同一模数集和同一双素数载体上，把真实权的差额转成两个分离权余项及一个显式绝对均值上界。两份均未经 Lean 内核验收。

**原权与共同网格。** 摘取 p 为原第一标号素数，固定第二个 t。原字典 trimmed_on 将真实标号素数对的截断权给为 naturalWeight(b,κ,s,κ₀,N,p,t)。actual_product 使用 offset true=[0,coord(N,t)] 与 direction true=[1,0]，恢复原 η(pt/N^(1−κ₀)) 及 manuscriptHalfProductCutoff(κ,N) 的四个实际光滑墙。四个 [0,1] 因子的方向由各自真实线性系数的符号给定，η 对首坐标单调。N>1、s>0 足以保证所用单调性，同一结论覆盖原物理调度的每个合法 s。

令 Δ(l,u;t) 为这五因子在整数 l、u 处的绝对差之和。local_oscillation 对所有 l≤p≤u 证明 |W(p,t)−W(l,t)|≤Δ(l,u;t)。total_oscillation 对任意 t、任意自然数 J 和任意单调 edge:ℕ→ℕ，给出 Σ_{i<J}Δ(edge i,edge(i+1);t)≤5。各因子先各自沿整个网格望远镜求和，再用取值在 [0,1]；重复端点和空网格均包含。这里不含随 s 变坏的导数常数。

**原算术核与正包络。** 字典的 kernel(N,d,x) 为 1_{x≡N mod d}−1_{(x,d)=1}/φ(d)。令 D_c(W) 是在同一 S,H,T 上对该核乘 c(d)W(p,t) 的有符号和。actual_window 对任意实系数 c、任意有限 S,H,T 和每个满足 H⊆[l,u] 的头窗给出
`|D_c(W)| ≤ |D_c(W(l,·))| + |D_|c|(Δ)| + 2(Σ_{d∈S}|c(d)|/φ(d)) · #H · Σ_{t∈T}Δ(l,u;t)`。
第二项仍然在同一 t,p,d 上减去其原互素均值。证明先用 |K|≤K+2/φ(d)，由进度指标和互素指标非负、互素指标≤1 得到该点式，然后用 Δ≥0、|W(p,t)−W(l,t)|≤Δ 对原有限和求绝对上界。因此末项是放宽互素限制后的上界，其符号和二倍因子都有来源。该证明也覆盖与 d 不互素的 p 或 t，无需额外单位条件。modulus_budget 使用 S⊆[1,N]、S 上 |c(d)|≤1 和既有倒欧拉函数和，给 Σ|c(d)|/φ(d)≤4(1+log(max(1,N)))。取 c=实际 ρ 后保留统一度量，毋须假设有符号尖锐密度。

**尚待合成。** 本对源码的输出保留两个矩形差和显式末项。尚需在实际 remaining∩activeLow 上给出选模数和物理 ρ、素数窗及不重复的宏窗分拆，支付小乘积区，检查大窗导子尺度、L¹/L² 和 SW 小窗，吸收 +1 和总窗数，把结果接回两个原 atlas。独审未发现这两份数学结论把后续分布结论当作前提。完整粗秩二付款与整图状态待后继源码。
