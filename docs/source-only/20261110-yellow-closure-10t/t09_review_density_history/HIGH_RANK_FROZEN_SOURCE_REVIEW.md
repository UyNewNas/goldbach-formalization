四项核对决定该结论的范围。

1. 原 `MediumAdmissible` 的前三个长度条件含同一个 U 及相同的三个模数长度。在 log 尺度分别取权 7、3、1 后消去 U。因为精度非负且局部尺度至少为 1，得到 (7/32)·log|T| + 8·log(Q1Q2Q3) ≤ 5·log(scale)。在原 `factorCarrier` 上三个实际因子各 ≤2Qi，因此 `physical_ceiling` 正确纳入 log 8。同一个目标满足 |T|=N，局部 scale≤CN，允许任意先定 dyadic 常数 C。原 nu·v=19/96 限制单个 rough prime。
2. `ordinary_small_word` 对所有旧祖先立方与积使用较强的统一 k+2 余量。偶数 k 先选且可任意大。标准 Bertrand 定理的已读原签名给出 n<p≤2n，排列在互不相交的连续二进区间，获得互异奇素数且皆与 2^D 互素。对应的第三素数介于物理 w 与 coarse N^a 之间，故实际第三历史进入 Θ−2e 的保底分支。继承祖先与未激活的第八分支均经过检验。
3. `even_word_rho` 链接实际 raw admission、偶秩正 ANY、单个小素数部分等于 1 和原 β+(1)=1。正负选取与 small/rough 唯一积排除在该 x 上的抵消。模数支持是完整物理系数的支持。
4. `original_factorial` 把取决于实际 tag 的权放在 tuple 求和内。`rational_row` 仅对一个有理斜率行及有界原整数槽给出严格或闭端的精确单槽 Fourier 表示及 O(log N) 的系数范数。两者仍需要完整 cell/tag、原分组和真实外层族的应用。`mediumSupport` 的否定没有涉及外层 W 的值、其他 PP 分支、整个 signed discrepancy 的大小或精确 β 加权后的渐近。
