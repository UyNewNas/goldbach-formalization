# T07 · 原种子两个 Γ₁ 与三个负窗的同 Q 计数

原 seed 取 S = 11/5、s₀ = 227/50、(φ₁,φ₂,φ₃) = (353/100,29/10,61/25)。在原 U3、U4 任一正种子位置集合 B 上，记 C 为原商素数计数乘原标记后求和，Θ 为相同 B 和相同冻结 Q 的物理质量。改进后的初始及四轮端点是

~~~text
5[C − (1 − 1/50)Θ] + E ≤ A − P + G + εΘ
5[C − (1 − J_{r+1})Θ] + E ≤ A − P + G + 5 J_r Σ_B m_l F_l + εΘ    (0 ≤ r < 4)
~~~

A 是原上 Rosser 的带符号 AP 和，系数分别为 4、1，截点分别为 s₀、φ₁。P 是三个原负窗对真实 π 居中的物理余数。G 是上次的 signedPositive，含 Γ5–8 和 Γ9–21 在各自原整数载体上的实际素数限制，扣除已定价的四块普通成本与 K_seed/4 转换成本。E 等于三个原母词的实际单素数计数减去相同三个窗的下 Rosser 多项式，经相同 σ(d) 聚合。E 非负。F_l 仍是上一包原三单、四双物理反馈，含 1/5。所有目标、公用冻结尺度、标记、多重出现、空族、原 4∶1 和阈值次序均在声明中。一般结论对每个固定 J < J₂ω 都成立。[真实端点](Part5OriginalH430SeedAtSignedAP.lean) · [七个反馈原定义](../Part5OriginalH430SeedSevenPhysicalWindows.lean)

## 同 Q 的普通筛主项

对 d ≤ N 和 z ≥ N^κ 有 dN ≤ z^(2/κ)。原随模数的 Mertens 估计因而适用于 dN，自然水平取 floor(Q/d) + 1。在 2 ≤ s = log(Q/d)/log z ≤ 10 上，原 JR 上下型和有符号下界预算给出实际多项式主项相对 θ(N,Q,d) 的两条单边界。此处 θ = 4 li(N) C(dN)/(φ(d) log(Q/d))，允许 Q 随原历史改变。全体阈值先于目标和标记子族选取。[物理两侧主项](Part5OriginalH430SameQCanonicalMains.lean) · [两个上锚点](Part5OriginalH430SeedUpperAnchorsAP.lean)

每个真实 q 满足 q∤N、q ≥ z；允许 q 重复以前的前缀素因子。原下 Rosser 对旧掩码 dN 使用 ceil(Q/(dq))，原 JR 使用 floor(Q/(dq)) + 1。若 Q/(dq) 为整数，则 q 整除整数 Q；冻结 Q 的有理幂表示给出 q∣N，矛盾。故两个水平相同。旧严格素数积和 ((dq)N) 的规范积也相等，因为 q ≥ z，两个积都只筛 p < z。对同一原系数取 φ(dq) 模型即可逐项使用上述下主项。[严格端点及原系数](Part5OriginalH430SeedChildRosserDictionary.lean)

三个原区间的上端依次是 5/11、10/29、25/61，公共下端是 50/227。它们与原 36 行中的第 0 行三窗对应。原有理下端不会等于实际 q 的对数坐标；上端仍开。用原单素数的有限求和及 Mertens 极限得三个积分和子 θ 总质量界。单个子项的参数是 (227/50)(1 − log q/log(Q/d))，截点 z 沿用父词。原三个真实 Rosser 均值共同支付原负项的三个普通积分。[原素数窗](Part5OriginalH430SeedOrdinaryWindows.lean) · [实际负均值](Part5OriginalH430SeedThreeNegativeMeans.lean)

## 四轮须保留的真实下界

原有限 21 项在把 Γ₂、Γ₃、Γ₄ 换为三个下 Rosser 多项式时丢去 E。新源在原 weightedQuotient 恒等式中把 E 完整留在左侧。旧平方与坏素数估计先支付原有限例外，π − li 的原密度平移随后按同一个 Θ 收款。因此两个锚点与三个普通均值的单边替换仍让下一轮在同一份原计数上使用上一轮可得的下界增益。全部三窗共用一次 ε 预算；重复的 q 出现按原三个窗分别求和。[原计数超额及精确有限恒等式](Part5OriginalH430SeedRosserCountCredit.lean)
