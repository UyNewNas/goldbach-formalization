本轮只实现稿内有限恒等式；稿外数论输入只登记，不新增证明、公理或假设式包装。

## 稿内完成到的候选源码范围

- 真实许可过滤树的完整第八层 frontier 按原 owner/trim 作 occurrence-list 拆分。
- 同一前缀、剩余 carrier 与 sign-dependent beta terminal 上的两种普通 continuation。
- 同一 full-q 的 AP、精确 coprime mean、实际 receiver 与 reciprocal-totient 密度关系。
- 模数素因子、中心素数和 primitive discrepancy 的三个显式有限绝对误差账目。

直接复用固定版本的有限集合、列表和实数基础；不重新实现数学库。
