首先核清了字段语义：`CapChoice.argument` 不参与 `freeze` 或 integer admission；`PhysicalFrozenPrefixHistory` 的 `queryLabel` 读取 child node 的 argument，并非 choice 的 argument。旧 tent bank 的 selected-sum midpoint 不能被改名为 H/h 查询。此次另外构造动态查询 receiver；有限 code 不负责保存盒内连续变化的 exact query。

`P2ActualSameQResidualQuery` 直接使用原 `P2EnhancedTwentyOneSameQWeighted.Phi/cutoff/Theta`。完整整数 history 的乘积为 B，全部物理坐标和为 S；对一个固定总层级 `Q=N^lambda` 与独立实际 cutoff exponent xi，证明 residual 为 `lambda−S`、实际查询为 `(lambda−S)/xi`，并回到原 cutoff 的精确等式。selected mask 不从 B 或 S 中删除。原 Theta 的 log denominator 精确化为 `(lambda−S)*log N`，保留相同 sigma、singular series、phi(B) 和原系数；这不是新的 density 或 H/h 均值估计。

变量物理 cutoff 会产生逐 B 的不同 query，源码将这种有限和与原 constant-query Phi 分开。固定 Q 的 singleton/pair receiver 保持原 marked slots，并按完整 prefix 更新 residual/alpha；alpha 不被重置为 2。全盒 query 给出真实闭区间，而非以 midpoint 代替。upper H430 的 `max(2,s)` 与 lower h248 的 `s<2` 取零、`s=2` 保留 h(2) 也分别定义。

`P2CanonicalTentDynamicQueryReceiver` 从实际 canonical `choose/select/checkedChoice` 提取 fresh SourceForm 与 source mask，inherit 保留原祖先 source。新 receiver 的 entire physical Trace 严格等于旧 run，因而保留 cap、accepted 和所有旧历史 frames；祖先查询 observation 也逐项保留。old/new 查询都用更新后完整物理 word，但分别使用 incoming/outgoing total。跨普通 cap replacement 的 Q 一般不同，没有被误称为 same-Q 后继。

原具体 tent chamber 的真实 last-prime 查询在 `[366/41,369/40]`，在选定点为 `369/40=9.225`；旧几何 midpoint 为 `181/1000`。源码证明二者不同。9.225 超出常见 `[1,5]` defect table，本次不给该 witness 任何 H/h 表信用。
