# Exact SmoothLicence repair installer

This wrapper uses the unchanged U reader and the fixed U collector helpers.
V binds the exact five proof splices, successful no-output probe, preserved
failed probe, actual U metadata, actual acceptance read and both public owners.
The executable must match its new publication exactly and descend from V.

Before mutation, it checks the original U Word/AllGroup 139/137 context, both
original run scopes, all owner evidence, unchanged dirty Git, 360 source slots,
160 modules' artifacts and the complete U/S/Q evidence trees. Only the exact
SmoothLicence source and failed setup are mutable. All other input paths stay
fixed. The source-after state is held; an absent setup is accepted only with
an exact same-publication, same-script durable archive receipt.

The setup is copied exclusively, fsynced and verified before the original is
removed. The unchanged U remaining-eight preflight then runs with the old
source and the newly empty failed owner slot. Only after it passes does the
original installer apply the single source replacement and make its backup.
Postconditions compare all source/artifact/runtime/Git slots and both accepted
U owner bindings. No Lean or kernel command runs in this installer.

Local targeted tests are described in `INDEPENDENT_FROZEN_UPDATER_REVIEW.json`.
They exercise the frozen wrapper and new guards; they do not replace actual
cloud preflight, installation or normal/kernel acceptance.
