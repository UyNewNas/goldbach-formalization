# P1.5 existing whole-atom dependency integration

This batch connects the existing REAL-endpoint fixed occurrence partition and
the original ordinary delta-reserve theorem in one isolated Member context.
Its 78-source selection and 30 original Member boundary inputs were frozen
before execution. Per-module acceptance is in modules/*/ACCEPTED.json. Only a
complete RESULT.json, independent final review and verified evidence package
permit publication as a completed batch.

The two targets are ImbalancedChen.P5SelectedRealWholeAtomGroups and
ImbalancedChen.P5OriginalOrdinaryWholeAtomDelta. The former uses the same
endpoint-computed slot lists for every actual tuple, including the full-vector
C<1 repair. The latter derives all three physical delta monomial reserves on
the full original interval 1<=A<=N^(1/3). Selected/full square, ordered rough
cube and original endpoint eligibility conditions are retained. These results
do not assert that every historical owner fibre is already a rectangular atom.

SOURCE_SELECTION.json records the source origin and initial digest for every
module. Thirty-eight committed P3.6 proof/API sources are reused. Their
original objects and source match original normal records; the original
export validator did not license transplanting arbitrary donor binaries into
this different Member context. The new integration therefore elaborates those
existing sources under the original Member guard and gives them zero new
mathematical credit. The static provenance diagnostics and their explicit
scope limitations remain in the adjacent reuse inventory. No lake update,
original guard edit, imported Member recompilation or broad repository build
is performed.

run.py is the exact frozen executed driver. Each new-context module must pass
guarded direct Lean, a kernel log replaying exactly that module, and the
original full owned declaration/type/universe/axiom inventory. Private and
generated declarations are included. Only Classical.choice, Quot.sound and
propext are allowed. Original compiler flags remain -t0 -j2 -M12288 and all
stages share the original serialized validation lane. This is isolated direct
Lean acceptance, not a Lake named-target or fresh imported-closure replay.

Every restart hashes accepted sources, direct project dependencies and output
facets, then reuses the accepted receipt without normal/kernel recompilation.
Failed attempts retain their exact source and diagnostics. The one interrupted
long simplification attempt retains its interruption record. Later repairs
touch only the first failing selected source. REPAIR_CLASSIFICATION.md maps
those repairs to their mathematical scope and the frozen 1106 manuscript.

The evidence archive contains exact selected/attempt sources, normal/kernel/
audit logs and receipts, new output objects and a per-member digest index. It
excludes the payloads of all reused import symlinks. verify_and_package.py
rehashes all accepted inputs and outputs, reparses the original full audit,
checks final-review source bindings, and verifies every indexed zip member.
It refuses a partial batch. Inherited source-only comments in unchanged
historical source bytes are superseded only by these precise context receipts.

Full P1.5 remains OPEN. This batch does not supply a full-domain uniform signed
medium estimate, the missing actual historical coefficient/rectangular-atom
identification, or a physical/free collision conclusion. Constants and the
threshold in that final estimate must precede all varying chart/row/mode/family
indices. The original proper-power register remains 18/21, with its three
recorded HOLDs. P3.4/P3.5 work is not recredited or silently promoted beyond
its original accepted scope.
