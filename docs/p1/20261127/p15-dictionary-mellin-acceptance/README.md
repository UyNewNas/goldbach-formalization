## What the new acceptance proves

on the original small/rough physical supports. The retention-mask difference
multiplies the original Mobius sign attachment; deleting a rough modulus
does not swap the original small Rosser plus and minus coefficients. Its
complex test identity and remaining-modulus specialization retain the full
product `a*b` in the original cutoff. This is an exact coefficient identity,
not the signed historical medium estimate.

The original Mellin profile is

```text
F(y) = Phi(y/U) * exp(i*t*log(y/U)).
```

For real C1 `Phi`, `M,D >= 0`, `|Phi| <= M` and `|deriv Phi| <= D` on
`[1,2]`, and `0 < U <= u <= v <= 2*U`, the accepted original conclusion is

```text
norm(F(v)) + integral_(u,v] norm(deriv F(y)) <= (M+D)*(1+abs(t)).
```

were preserved byte-for-byte. Repairs address the real derivative cast,
definitionally equal real module instances on Complex, a ContDiff API use,
absolute-value token spacing and two proof-tactic issues. Unused project
imports were removed. The old import closure already contained Mathlib;
the parser problem is not attributed to introducing the umbrella import.
The frequency price is still linear in `abs(t)` and is not an SW bound
uniform over unbounded frequency.
