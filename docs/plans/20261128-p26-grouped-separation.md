# Original sibling-cone certificates

This continues the authorized P2.6 proof with the original thirteen families,
28,918 row ordinals and fixed numerical scales. The existing Cell00 integral
verification remains a separate chain.

1. Reconstruct the pulling recursion from each original face ledger. Map
   every leaf to its original nine-vertex row and check the complete original
   row inventory. This is an advisory host check, not a coverage theorem in Lean.
2. For a child facet, solve the rational affine interpolation equations:
   zero on that facet and all ancestor pivots, one at the current pivot.
   Check nonnegativity on the current face. Differences of two child forms
   propose sibling-cone separators. Check their nonzero linear parts and all
   original child-face and ancestor vertex signs using exact rationals.
3. Prove a generic Lean composition lemma: proper rational separating forms
   imply almost-everywhere disjoint actual affine simplices; finite child
   group pairwise relations flatten; a proved original leaf inventory yields
   pairwise disjointness of the full indexed family. No numerical or integral
   lower bound is a premise of this geometric lemma.
4. Pilot the construction on already accepted Cell05 physical simplices.
   Emit 45 forms, 49 branching nodes and 61 sibling witnesses. Closed Lean
   checks use the actual original parser-bound rational vertices. Compose
   those certificates and prove the leaf list contains every original
   ordinal. Obtain all-pairs almost-everywhere disjointness of all 56 original
   physical simplices without a quadratic list of pair certificates.
5. Normal-compile, stock-kernel check and fully inventory/audit all new
   owners. Preserve the generic and pilot receipts separately from Cell00's
   source-integral capsule. A successful pilot does not accept another cell.

The current all-thirteen host proposal has 42,600 sibling pairs and 23,553
distinct-per-family forms. It has zero additional original-family Lean
credit until its corresponding finite certificates are actually checked.
In particular, the Cell12 proposal replaces 21,776,700 pair candidates with
10,095 sibling candidates; that is an efficiency proposal, not a completed
