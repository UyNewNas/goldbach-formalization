### A5: a complete adopted two-chart coarse integral

The selected field is `no_grid_coarse_lower=640339/15210735000`. The finer 2,048-row alternative has a larger result and is **not** another selected gain. The exact frozen source is `proof-library/source/second-prefix-upper-fallback-20261009.tex`.

Put `mu=25/128`, `rho=19/96`, `h=1/384`. The physical region is `mu<x<rho`, `25/32-3*x<y<x`. With `v(t)=min((1+t)/2,57/64-3*t/2)`, its actual saving kernel is

`4*(v(y)-v(x))/(x*y*(v(x)-x-y)*(v(y)-x-y))`.

For `k=-3,1`, the two charts use `0<u,v<1` and

- `x=(75+u)/384`, `y=(75+k*u*v)/384`;
- `Ro=(159-5*u-2*k*u*v)/768`, `Rn=(159-2*u-(2*k+3)*u*v)/768`;
- absolute Jacobian `abs(k)*h^2*u`;
- integral `6*abs(k)*h^3 * integral_0^1 integral_0^1 u^2*(1-v)/(x*y*Ro*Rn) dv du`.

The four denominators are positive on the closed square. For `k=-3` they are bounded above by `(rho,mu,5/24,5/24)`; for `k=1`, by `(rho,rho,53/256,53/256)`. The exact numerator integral is `1/6`, giving `3/95000` and `32/3042147`. Thus this coarse bound can be certified directly without obtaining the large archive. The source distinguishes its endpoint-tree limit from an arbitrary frozen finite tree; finite realization and the rough-cutoff tail remain a separate semantic interface.

## Checks actually performed for this catalog

The portable audit is `verification/part2/audit_adopted_catalog.py`. Give it a checkout or raw-file snapshot of the frozen manuscript repository, preserving exact file bytes:

```sh
python3 verification/part2/audit_adopted_catalog.py --source-root /path/to/chen-imbalanced-semiprimes --output /path/to/audit-result.json
```

The script checks the checkout HEAD when a `.git` entry exists, verifies every listed source against both Git blob SHA1 and SHA256, and reads all numerical inputs from that source root. A snapshot without `.git` is reported as file-identity verification, not as a local Git HEAD check. It requires only Python's standard library, performs no network request and does not edit the supplied sources. The actual execution report is `adopted-audit-result.json`.
