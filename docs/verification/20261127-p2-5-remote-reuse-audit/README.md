## Search controls and limits

The production repository, index, worktree and compiler environments were not changed. Only an isolated bare object store under this directory was used. The initial production repository was shallow, and 484 of the 485 advertised head commits were absent locally; absence alone was not treated as proof of unrelated ancestry. The first filtered seven-head fetch caused an auxiliary 302 MB blob pack despite the direct requested pack containing only commits and trees. Later commands set `GIT_NO_LAZY_FETCH=1`, disable automatic maintenance and use bounded explicit retrieval. The remaining 477 head trees added only 1,644,501 bytes. No further broad content download was performed.

Coverage is the frozen advertised branch-head snapshot, not all deleted history, tags, hidden refs, future updates, arbitrary renamed implementations or remote runtime cache directories. Path matching includes Saving16, P2.5, fourteen/ascending-family and eighth-prefix names. No Lean compiler, MCP compiler command, numerical certificate evaluation, new proof generation or publication was performed.
