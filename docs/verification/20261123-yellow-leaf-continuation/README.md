## 数学内容与实现变化

六阶余项保留 R6(y)=log(1−y)+Σ(k=1..6)y^k/k，通过精确导数 −y^6/(1−y) 及凹性支付整个余项，得到真实正权概率测度下的 log 矩界。只修正函数逐点加法的展开和导数标量恒等式的使用；原定义、14 条声明及其假设不变。物理单纯形质量、真实矩、域覆盖仍由各自原输入负责。

Q80/Q96 文件连接原实际矩与二进制有理向下舍入。修正只将末尾自动化简限定为整数 cast 的 floor 恒等式，防止先分配 cast 后失去可匹配形状。保留 Q80 的 log-gap 与 Q96 的积分下界方向、原系数 4，以及 Python 整数除法语义；没有用数值行的存储值代替其真实积分语义。原源来自 6848b4a 的 full87_helpers，本提交把实编后像安装为标准模块路径。

宽度导数预算原代码已有，不重新证明：本轮复用其固定阶数先选常数、随后对所有正宽度给 C_k/width^k 的真实阶梯界。它仍不是完整多变量混合 Euler 或 PP 许可。

联合窗口模块构造所有前缀上下墙的乘积光滑因子，保持半开原窗口、严格非零支撑和相同乘法宽度；在外部 collar 的并集之外精确等于原矩形指标，空前缀和重复槽也在原声明范围。它不单独支付真实整数墙误差、完整 W1/W2、Gamma 或同 rho PP；后续实际载体源码有独立验收状态。

曲线辅助把一个给定连续单位模界权重的积分写成三个固定连续曲线路径的均值组合；路径与常数先于测试函数选取。它为实际 Fourier 权重接入已有参数正则性提供合法换元，不能替代连续谱、ABL、谱隙或全部 7/32 费用。

粗糙度模块对全部实数 x≥4 证明 2<x^(1/(log(log x))^3)。证明使用固定 Mathlib 中 e 与 log 2 的有理数界及指数函数切线不等式，未添加额外数值公理。它为实际图表中偶数 N 的对角乘积消除提供输入；必须保留原 rough 投影，不能把结论转用于移除投影后的算术表达式。

固定宽度素数质量模块复用 Mathlib 的 Chebyshev 上下界，证明对所有充分大的实数 x，预先指定的窗 (x,64x] 上素数倒数和至少为 1/(64 log x)。窗口宽度先于阈值固定，x 可在阈值后取值。这一步供给稿件所需稀疏正质量族的底层质量；除去 N 的素因子、原整数系数为 +1、原策略共同 Q 与最终相对 Θ 的使用均另行绑定。

有理幂端点模块证明：若 q 为素数、q 与 N 互素且 den≠0，则 q≠N^(num/den)。将等式提升到整数幂会推出 q 整除 N，和互素矛盾；不额外假定 N>1。它将原 417/5000 截断的弱不等号转成严格不等号，为实际历史中的 fresh 路径提供输入。
