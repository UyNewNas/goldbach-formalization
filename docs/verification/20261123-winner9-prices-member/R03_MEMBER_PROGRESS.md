## 独立审查后的范围澄清

四份源码中的混合 `open A B (names)` 命令已按当前 Lean 命令语法拆成两个命令；数学定义、公开声明与导入保持原样。这是源码层修正，11 份组合模块仍未编译。

`upper_member_medium` 的局部尺度还显式要求 `1 ≤ q`，其中 `x^q=N`。原稿的 `c₀x≤N` 允许 `x>N`，因此尚须补齐缩放或指数缓冲桥才能覆盖全部原 trim；本轮四项大小条件只在声明列出的局部尺度假设下成立。残余 `h` 的两项解析估计把 retention 与 cap 放在最终 `∀ᶠ N` 之后，可在每个 N 代入该历史的实际 retain；完整 `B*h` 的估计仍未给出。

`original_marked_progression` 的互素结论保留实际 sifted 接收值 r 的前提；它没有覆盖空 receiver fibre 的非零均值。已有 `rootHistory_coherent.letters` 与 `actualSmallRoughModuli_coprime_target` 可用于补齐不依赖接收值的互素接口。已有 `chenQuotientPrimeSource_divisibility_fibre_card` 在未筛载体上直接给原 AP 计数减去 center-prime 修正的精确基数，可继续复用。两者都不能代替完整有号 AP 估计。

原政策的 ν、β、ζ 和对数阶数须对整个带标记平均共同冻结；在每个 N、每个 Member 上统一的残余 h 界，也尚未给出对随 N 改变的 B 的总求和支付。

公开清单仅删除内部来源路径，并将项目源索引分片。源码的数学内容、准确哈希与全部导入边均保留。逐模块当前验证状态和代码位置见验证目录 `SOURCE_FILES.json`。
