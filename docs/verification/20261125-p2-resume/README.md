### Global physical extension and support

The physical domain has separately tagged old, fresh, and tail coordinates:
`Fin k ⊕ (Fin 2 ⊕ Fin r)`. The prefix is the sum of all old logarithms, and
the complete product contains every occurrence. Equal numerical values do
not identify separate slots.

The reused positive-argument and floor functions give a globally smooth
formula. On nonzero floor support, every coordinate exceeds `b/2`, so the
safe logarithm is exactly the original logarithm. Above the original
positive cutoff `b`, all floors equal one and the original profile is
restored. From the actual product gate, nonzero weight implies
`physicalProduct < exp(width) * N`. With `d = k + 2 + r`, the coordinate
upper bound is `exp(width) * N / (b/2)^(d-1)`. This derives compact support;
compactness is not a premise. Empty old and tail blocks remain valid.
