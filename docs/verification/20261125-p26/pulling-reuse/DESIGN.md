# Saving19 original pulling reuse candidate

Root authorized an independent candidate under this directory, with no production
or P1 changes. The target is the existing all-original-row within-cell null-overlap
statement used once by OwnedIntegral. The already implemented Winner9 generic
`checked_pulling_overlap_null` is reused; its numerical Winner9 tables are excluded.

The 2026-11-06 manuscript permits positive-saving bounds on a subset
(`argument.tex` 1098–1103) and calls for exact original inequalities/vertices and
face incidences before pulling (`numerical-appendix.tex` 177–196). No coverage or
new analytic theorem is proposed.

## Chosen construction

- Actual gates and rational points remain those of Saving19 OwnedSource.
- A flag index is a bounded index into the actual `facetVertices` array. Its
  corresponding Fin 97 gate is chosen only from the closed, complete zero-set
  equivalence obligation already present in original_pulling_checks.3.
  `facetOriginalIndices` is never coerced or reduced modulo 97.
- Each original ordered nine-ID row is traced through the actual face ledger.
  Every step checks its recorded pivot, a recorded child not containing that
  pivot, and the exact intersection with a global facet. Failure remains Option
  none. A closed theorem must show successful trace plus the existing pullingCheck.
- Zero masks are bit encodings of the actual facet vertex lists. A small generic
  bit lemma proves membership exactly, including duplicates and high indices.
- Row keys encode actual vertex-ID sets. Sorting the complete original-row key
  list and checking adjacent strict increase proves key/vertex-set injectivity.
  This replaces a new pairwise numerical enumeration, not the retained obligation.
- The existing nonnegativity guard is reused. The physical support representations
  are connected by the already established row_vertices/interpolation identities.

## Alternatives and boundary

Keeping the old per-row adjugate/leading-coefficient certificate would retain a
separate expensive proof of explicit polynomial identities unused by OwnedIntegral.
Those identities remain unproved by this candidate. Reusing Winner9 flag, gate,
point or rank tables would address different data and is excluded.

Only the finite helper may receive a local Mathlib-only normal/kernel check. The
actual Archive/OwnedSource dependent connector will remain clearly uncompiled;
its closed proof requests do not acquire acceptance credit. No original numeric
or source-inclusion obligation is replaced by an assumption.
