# v9 successor gate map

This map describes the new driver, not a successful compiler run. The complete
actual attempt008 export and selected source metadata have been reviewed and
pinned. Old attempt008 remains a failed aggregate even though its OriginalParse
owner is accepted. No new remote preflight or compiler gate is claimed here.

## Scope and source selection

The immutable historical selection still contains five owners. v8 selected
four fresh owners after accepted Decoded. v9 selects only OriginalFloors,
OriginalArithmetic and OriginalSourceFacts. Accepted Decoded and OriginalParse
are dependencies. The complete graph still contains 45 modules.

The original symbolic Field and Parse source selectors are unchanged. v9 first
reconstructs the original v8 source graph and compares it with the actual old
receipt. It then applies the separately pinned Floors override. The independent
pending-source selector adds only root's explicit selection of the existing
Arithmetic and SourceFacts postimages. Exactly those three rows change only
path and source SHA; imports and public interfaces remain equal, and the other
42 source rows are identical. The original Floors selector is unchanged. No
production Lean source or immutable v8/recovery file is edited by the driver.
