# Reused original Moment01 suppliers

`suppliers.tar.xz` preserves the existing 88-module source/object closure through
`ImbalancedChen.P2OriginalSaving19Moment01Shape`, together with the original
normal/kernel receipts, logs, fixture, and full-closure manifests. Its size is
3,088,264 bytes and SHA-256 is
`e5008887d1a13751396644280bd89c796052c2f3339d38f56c1143e5ae006181`.

All 88 source files match the source-closure branch at `5f72712d0bc3effc005f73f378c13976edc88c65`.
The original 81 Moment01 owners and seven generic suppliers are reused without
compilation. Source/object/receipt/log hashes were checked before this archive
was created. The seven generic suppliers match the geometry01 cache exactly.

This publication preserves a previously accepted parsing, decoding and finite
shape checkpoint. It does not assert the new Cell01 row000 arithmetic or floor
pilot has passed, does not assert all 144 rows have floor certificates, and does
not close P2.6.
