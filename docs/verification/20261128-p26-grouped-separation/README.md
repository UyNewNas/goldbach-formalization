# Original sibling-cone separation: verified Cell05 pilot

The new generic composition lemma and the original Cell05 pilot passed
four normal compilations, four stock-kernel checks and two complete-owned
audits. All 232 owned declarations are safe, total and nonaxiomatic; their
transitive axioms are contained in `propext`, `Classical.choice` and
`Quot.sound`.

The pilot proves `all_original_pairs`: all 56 original physical Cell05
simplices are pairwise almost-everywhere disjoint. It uses 45 rational forms,
49 branching nodes and 61 closed sibling-cone witnesses. Every sign is checked
on the original parser-bound rational coordinates. A closed Lean theorem
checks that the root leaf list contains every original row ordinal.

`P2OriginalSaving19GroupedSeparation` converts proper rational vertex-sign
certificates to almost-everywhere disjoint actual simplices, composes child
groups using `List.Pairwise`, and transfers the root relation to the original
indexed family. The pilot imports the accepted physical construction. Its
source closure contains none of the earlier quadratic Cell05 separation
certificate modules.

`CAPSULE.json`, the phase directories and `owned-declarations.json` bind the
actual source/object/command/log bytes and complete types. The object archive
contains only the four new modules. The final external-input readback is shared
with the Cell00 capsule and was executed after both new verification chains.

## Remaining finite certificates

`all13-pulling-proposals.tar.xz` contains exact-rational host proposals and
their reconstruction scripts for all original 28,918 rows. Their 42,600
sibling pairs use 23,553 distinct-per-family forms. All thirteen original
leaf inventories and proposed signs were checked on the host. For Cell12,
the proposal has 10,095 sibling pairs instead of 21,776,700 simplex pairs.

These additional host proposals have `formal_acceptance=false`. The verified
finite pilot covers Cell05 only. The other original families still require
their parser-bound finite Lean certificates, numerical attachments and source
integral bounds. P2.6 and its global endpoint remain open.
