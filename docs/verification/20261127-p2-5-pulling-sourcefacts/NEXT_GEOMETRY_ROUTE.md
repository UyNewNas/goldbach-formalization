# From the original pulling rows to the positive saving integral

The original integral lower bound needs the union of retained simplices to lie inside the source region up to null sets, with pairwise null overlaps. Nonnegativity on the source region permits discarding its complement. The frozen manuscript describes the full reverse-pulling triangulation and explicitly permits a positive saving to be bounded on a subset. The lower-bound route below does not require a whole-cell coverage theorem.
